# 2026-10-04：SUMMARY-batch4 性能选择与实现

依据 `shader_research/SUMMARY-batch4.md`，对照当前 Astra 水体、粒子、阴影、天空缓存与本机 Iris 1.11.2 实现。本轮选取减少重复计算与无贡献读取的方向；没有把报告中的新增效果清单直接转换成开发范围。

## 已实施

| 位置 | 修改与适用范围 |
|---|---|
| `global/water/raytrace.glsl` | 同一深度像素重复访问时，复用视空间 Z 与逆齐次 W。只有逆投影矩阵的 Z/W 行均不依赖屏幕 XY 时启用；否则保留逐次完整重建。界面侧平面仍按当前精确 UV 求值，避免错误接受岸线另一侧的交点 |
| `program/water.glsl::water_sample_path` | 岸上水面与冰反射把 SSR 已返回的命中深度传给后续颜色／介质采样，省去同一锚点的一次深度读取。其他折射入口通过原签名的重载继续自行读取；滤波角点仍各自配对深度与颜色 |
| `program/water.glsl::astra_underwater_interface` | 完整置信度命中时，跳过不会参与结果的 48 格备用水雾与颜色域转换。未命中和部分命中仍按原顺序混合备用水雾与命中颜色，保持全反射窗口的水下底色 |
| 同上，天空透射分支 | 先判断背景是否是天空；天空路径直接使用原折射方向天空／云查询，省去随后会被覆盖的场景颜色读取及三通道幂运算。几何路径继续读取原场景颜色，显式取已有的第零级，避免把隐式导数查询移入分支 |

保持现有射线粗查／细化次数、增长步长、厚度容差、置信度与界面侧判据。没有增加邻域深度方差查询，也没有用距离阈值直接接受反射交点。水体色谱、浅水体积、波面、焦散、光束、花草投影与刚完成的夜空群星参数均沿用现行实现。

## 对报告各项的选择

| 报告项 | 结论 |
|---|---|
| A① 方向性体素彩光 | 是新增光照塑形，增加三维纹理读取；不属于当前减少开销的必要改动 |
| A② 水下 SSR | 采用按现有路径减少重复工作的方向，具体实现为上表。Astra 没有参考实现的随机 SSR 抖动，不能直接移植抖动收敛；放宽深度容差和前几步减半也会改变当前命中行为 |
| A③ lightmap 直接除 240 | 保留矩阵路径。当前 Iris 的 VanillaTransformer 与 SodiumTransformer 都将 `gl_TextureMatrix[1]` 转为 `iris_LightmapTextureMatrix`；仅看到原顶点属性范围不足以证明直接除 240 与该矩阵的缩放／偏移相同 |
| A④ 主色缓冲不清空 | 保留主色清空。当前主世界日月采用加法合成，多个天空及介质分支也依赖空背景；省去清空需要完整生产覆盖依据，不能只看 deferred 最终写满屏幕 |
| A⑤ 阴影 mip | 不添加无收益声明。本机 Iris 的 `PackShadowDirectives$SamplingSettings` 构造函数把 `mipmap` 初始化为 false；深度设置继承该值，Astra 当前没有启用阴影 mip 的指令 |
| B① 粒子简化光照 | 保留粒子的既有阴影、方向光与介质衰减，避免烟雾／水下粒子失去空间层次；也不新增粒子合成缓冲 |
| B② 主世界屏幕彩光 | 新增光照系统及多个阶段，会增加开销和屏幕空间近似边界；本轮不接入 |
| B③ 半球天空图 | 保留当前天空缓存布局。修改布局需同时考虑资源尺寸、粗糙 mip、所有消费者与边界过滤；报告没有提供当前布局存在成本瓶颈的直接依据 |
| B④ 另加软天空图 | 已有粗糙度 mip 查询，无需新图及生产阶段 |
| C① 位掩码 GI/AO | 属于新间接照明路线，不以增加射线和历史系统完成当前性能目标 |
| C② DH 边界 | 当前没有已接通的 DH 光栅路径，不为不存在的消费链增加剔除代码 |

## 关键纠正

1. 报告称 dercode 远处接受命中会「省掉细化」。其原代码只跳出粗查循环，后面的 `RAYTRACE_REFINEMENT` 仍不区分远近执行；该描述不能作为降低细化开销的依据。
2. 报告称 Astra 唯一不清空的缓冲是 `colortex6`。当前云历史、曝光、下界反射、光束历史和 TAA 等多处已有对应 `Clear=false` 声明，不能将共用设置文件中的单个声明当作全项目统计。
3. 普通 L1 八面体投影并非严格等立体角；无经线接缝也不代表折叠边界的 mip 过滤可以直接沿用经纬图。没有仅因报告中的「等立体角」描述替换现有环境图。
4. 阴影 mip 默认关闭由本机实际 Iris 包的类实现确认。显式再写 false 不会消除一条原本存在的 mip 生成工作，不能计为本轮性能收益。

## 源码复核与状态

逐段确认了同像素 Z/W 复用的矩阵条件、天空像素不会使用旧的重建记录、SSR 返回深度与采样锚点对应同一个 `depthtex1` 像素，以及所有折射入口仍使用原有读取分支。完整反射命中时备用颜色权重为零；天空透射时旧的场景颜色会被完全覆盖，裁减这两类工作不改变颜色混合域。

本轮只改动两个渲染源文件，无新增选项、纹理、缓冲或渲染阶段。同步到当前游戏光影目录。收益取决于反射覆盖率、重复访问次数及完整命中比例，当前没有本轮新的游戏帧率数据。
