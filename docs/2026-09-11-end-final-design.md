# 末地最终效果设计书（实现交给 GPT）

**本文件只定义"最终应该看到什么"，不含实现方案、不设成本上限。**
实现方式、性能取舍、代码结构由执行方决定；本文的一切描述都是**验收目标**。

---

## 一、总体意图（一句话）

> 末地不该是"天上挂了几个东西"，而应该是**你在一个星系内部**：
> 头顶是另一个恒星的残骸，脚下是它的碎屑盘，你在盘中，盘在缓慢地转。

三条不可违反的气质要求：

1. **静**。一切运动都要慢到"盯 10 秒才察觉"的量级。任何被一眼看出在动的元素都是失败的。
2. **深**。黑要黑得下去，要有大量**空的区域**。密度感来自层次，不是来自覆盖率。
3. **冷中带暖**。主体是冷调（星光、暗蓝），唯一的暖源是黑洞的吸积盘。暖色必须稀缺才珍贵。

## 二、空间模型

### 2.1 存在什么

末地所处的系统有三层结构：

| 层 | 是什么 | 距离感 | 角色 |
|---|---|---|---|
| **L1 背景** | 深空星场 + 极稀薄星际尘埃 | 无限远 | 底，提供"深" |
| **L2 环系** | 围绕末地世界的一圈碎屑盘 | 极远（天球级） | 主体，提供"系统"与"公转" |
| **L3 主天体** | 黑洞（事件视界 + 吸积盘 + 光子环） | 远 | 主角，唯一暖源 |

**关键关系**：L3 必须**偏出 L2 的环面**（不在同一平面）。这样两者才会**交错**——环带会周期性地扫过黑洞，产生"环食"。若二者共面，画面会退化成一个平面剪影，失去纵深。

### 2.2 环系的空间姿态

- 环系的**对称轴 N** 相对世界竖直方向倾斜 **28°**。
- N 绕世界竖直轴**极慢进动**：**36 分钟一圈**（可调 20～60 分钟）。
- 环面本身**绝对固定**，不随时间摆动——变化的只有 N 的进动带来的整体姿态漂移。

### 2.3 环系的径向结构

环不是均匀的带，而是有**分层的环缝**（这是"真天文感"的来源，也是避免"抹痕感"的关键）：

| 环带 | 归一化半径 | 宽度 | 密度 | 说明 |
|---|---|---|---|---|
| 内晕 | 0.00–0.18 | 窄 | 极稀 | 靠内缘的零星尘埃 |
| **A 环** | 0.18–0.42 | 宽 | 高 | 主环，最亮 |
| **卡西尼缝** | 0.42–0.50 | 窄 | **0.03** | **边界锐利**，几乎全黑，是画面上最重要的"断口" |
| **B 环** | 0.50–0.78 | 最宽 | 中高 | 次亮，内部有 3～5 条细缝 |
| **恩克缝** | 0.78–0.82 | 极窄 | **0.05** | 窄而锐 |
| 外晕 | 0.82–1.00 | 宽 | 极稀、颗粒粗 | 逐渐消散进星场，**外缘必须柔和** |

要求：
- **缝的边缘必须锐利**（1～2 像素的过渡），环带的密度变化必须是**阶跃**而非渐变。
- **外缘必须柔和**（几十像素的渐隐），避免"贴上去的带子"。
- 每条缝里允许有 1～2 条极细的、断续的亮线（牧羊天体附近的开环）。

## 三、分层规格

### L1 背景星场

| 项 | 规格 |
|---|---|
| 密度 | 稀疏。亮度高于阈值的星约每平方度 6～10 颗 |
| 星等 | **幂律**：绝大多数极暗，极少数显著亮。**不允许出现亮度相近的大批星** |
| 色温 | 黑体 3000K～12000K，冷蓝为主，暖橙点缀（约 1:6） |
| 闪烁 | **禁止**。星是无限远的点，不该闪 |
| 自转 | 极慢，**60 分钟转 1°**（远低于可察觉阈值，但长期观察会发现） |

**尘埃消光**：位于环带之后的星，亮度下降且**偏红**（不是直接删掉）。这是"深"的关键细节。

### L2 环系

**L2-a 远景尘埃（连续成分）**

- 覆盖上表全部环带，密度按表
- 材质：**各向同性散射的细尘**。光来自黑洞，因此环带上**朝向黑洞的一侧更亮**
- 颜色：基色冷白（`vec3(0.62, 0.66, 0.78)`），越靠近黑洞方向越偏暖
  （向 `vec3(0.95, 0.80, 0.62)` 过渡）
- 环**自身投影**：位于"黑洞背光侧"的环带段要**变暗**（环被自己挡住）——
  表现为环带上有一条**宽的暗带**，其位置随黑洞方向固定、随环进动扫过

**L2-b 环缝**

- 密度接近 0，但**不是纯黑**：保留 3% 的极稀薄尘埃，使其在亮环衬托下是"深灰"而非"空洞"
- 缝内允许极细的亮环（宽 1–3 像素），颜色偏冷

**L2-c 近景碎块（离散成分）**

- 约 **40～80 个**可分辨的独立碎块，分布在环带内外
- 尺寸分级：3～5 个**大型**（视角直径 2°～4°），其余依次递减到几乎只是一个亮点
- 形状：**角状、多面体感**，不是圆球。要有明确的棱边
- 材质：末地石色（`vec3(0.85, 0.84, 0.56)` 的高光面 + 暗面），**带一点自发光感的岩质**
- 光照：
  - 朝向黑洞的一面被照亮，背面近黑
  - **边缘处出现细亮的轮廓光**（rim），宽度不超过碎块直径的 5%
  - 当碎块位于"观察者—黑洞"连线的**对面**时，出现**冲日增亮**（opposition surge）：
    正面整体亮起，这是真实的环形颗粒光学行为，也是画面上的高光点
- 运动：沿环带**差速公转**，内圈快、外圈慢。角速度比约 **1.0 : 0.62**（不是开普勒的 1:0.35，
  那个太夸张、会显得乱）
- **必须是"流动"而不是"闪动"**：同一条环带上的碎块要能看出**相互错开**，形成缓慢的剪切纹理

**L2-d 牧羊天体**

- **2 个**大型天体，轨道半径分别位于恩克缝与卡西尼缝内
- 视角直径 1.5°～2.5°
- 它们**清空了自己轨道附近的环物质**：各自周围有一个宽度约 0.6° 的开环
- 表面：可见的大型岩质天体，有巨大的撞击坑阴影（用低频率的凹凸法线）
- 它们**绕过黑洞时会明显遮挡黑洞**，是环食事件的主要触发者

**L2-e 悬空岛群（环绕末地岛公转的岛体）**

这是"围着末地岛公转"最直接的表达：**一圈末地风格的悬空岛体，在极远处缓缓环绕**。
它们**不坐在环带上**，而是各走自己略微不同的倾角与半径，因此会与环带**斜交**——
正是这种交错产生纵深。

| 项 | 规格 |
|---|---|
| 数量 | **6～8 个**，视角直径 **3°～9°**（最大的接近环带宽度） |
| 形态 | **末地自身的岛形**：顶部起伏的平台、向上抽出的尖柱、向下收窄的锥形岛底。轮廓必须一眼可辨认为"岛"，不允许是团块 |
| 细节 | 岛顶可见数根竖直尖柱；岛底有破碎的悬垂结构；岛体侧面有层次的岩层感 |
| 材质 | 末地石色（`vec3(0.85, 0.84, 0.56)`）受光面 + 深紫灰暗面 |
| 光照 | 朝黑洞侧受光；轮廓有细亮边缘光；**黑洞位于岛体之后时，岛必须变成纯剪影**（逆光） |
| 运动 | 各自沿独立轨道公转，周期 **24～52 分钟**且互不成整数比；绕行方向**不完全一致**（至少 2 个反向） |
| 遮挡 | 岛体**必须能遮挡环带与星空**；经过黑洞前方时**遮挡黑洞** |
| 视差 | 岛体位于环带**之前**（视觉上更近），移动时相对环带有轻微错动 |

**关键区分**：L2-c 近景碎块是**小、密、规矩地沿环带流动**；L2-e 悬空岛群是
**大、稀、各走各的轨道**。两者叠在一起，画面才会同时有"盘在转"和"岛在绕"两层运动。

### L3 黑洞

沿用现有实现（事件视界 + 光子环 + 吸积盘 + 多普勒 + 差速自转），但**尺寸要显著放大、
体积感要显著加强**。

#### L3-a 尺寸（实测现状 → 目标）

| 项 | 现状 | **目标** |
|---|---|---|
| 事件视界阴影**视角直径** | 约 **6.5°** | **12°～13°**（约 1.9 倍） |
| 光子环 | 紧贴阴影外缘 | 阴影外缘，宽度 **不超过阴影直径的 1.5%** |
| 吸积盘投影椭圆 | 未明确 | 长轴 **约 30°**，短轴 **约 9°**（强透视压缩） |
| 引力透镜影响范围 | 局部 | 星场在中心 **±25°** 内可见明显畸变 |
| 在画面中的地位 | 一个"小亮点" | **玩家抬头时应当占据视野高度的 1/4 以上** |

> **放大时必须注意的几何关系**：视角尺寸只取决于 `视界半径 / 观察距离` 这个**比值**。
> 把所有尺寸统一放大**不会**让它看起来更大。要放大，必须**减小观察距离与视界半径之比**
> （约降到 0.55 倍），并**同步缩小吸积盘的内外半径**，使观察者仍然位于盘的**外侧**——
> 否则观察者会落进盘内，画面彻底崩坏。march 的起点、步长与步数需按新尺度重新标定。

#### L3-b 体积感（决定"是球体"还是"贴纸"）

以下七条按重要性排序，**前三条是不可妥协的核心**：

| # | 规格 | 为什么关键 |
|---|---|---|
| 1 | **吸积盘的近侧必须从阴影前方横过** | 一条遮挡关系就能建立"盘在球前"的纵深，胜过任何明暗处理 |
| 2 | **吸积盘的远侧必须被引力镜头顶到阴影上方**，形成横跨顶部的弧 | 这是黑洞最标志性的视觉签名，也是"三维"的核心证据 |
| 3 | **阴影内部不是纯黑**：应当看到被强烈透镜压缩的**微弱星场**（次级像） | 纯黑会被读成"洞/贴纸"；有内容才读成"球体把后面的光弯了过来" |
| 4 | 盘具有可见**厚度**（约为盘半径的 6%～10%），侧缘能看到层状结构 | 零厚度的盘是平面图形 |
| 5 | **多普勒不对称**：朝向观察者的一侧亮度可达另一侧的 **3 倍**，并轻微偏蓝 | 真实物理，也是唯一的"动感"来源 |
| 6 | 光子环**极细极亮**，并带有**收敛的泛光晕**（光晕半径不超过阴影直径的 20%） | 泛光必须收敛，糊开就毁了锐利感 |
| 7 | 盘内物质**差速自转**（内快外慢），能看出剪切 | 已有，保留 |

#### L3-c 与环系的相互作用

| 项 | 规格 |
|---|---|
| **环系的引力透镜像** | 位于黑洞后方的环带必须被拉成**环绕黑洞的弧**。这是全画面**最漂亮的一个细节**，必须有 |
| 爱因斯坦环 | 在主环之外形成一圈极细的、由**被透镜的环系**构成的亮环，亮度低于光子环 |
| 亮度层级 | 吸积盘峰值 = 画面最亮；**比环带亮至少 8 倍**；环带又比星场亮 |

## 四、动态设计（时间表）

以 **36 分钟**为一个完整周期（进动周期）。玩家的体验节奏：

| 时段 | 画面 | 玩家感受 |
|---|---|---|
| 0–8 min | 环带斜跨天空，黑洞在带外清晰可见。环带缓慢地"变宽又变窄"（进动导致视角变化） | 安静。发现环带在动 |
| 8–16 min | 牧羊天体从环带中移出，身后拖着一条暗淡的开环；环带的暗带（自投影）扫过视野 | "这里有结构" |
| **16–19 min** | **环食**：环带的一个密集段（或牧羊天体）横过黑洞。黑洞的吸积盘被切出一道锐利的暗带；同时全场光照**缓慢变暗约 18%**，持续 40～70 秒后恢复 | 高潮。会停下来看 |
| 19–26 min | 环带逐渐移开，暗带消退。近景碎块开始被黑洞照亮，出现连续的**冲日增亮**闪烁 | 回味 |
| 26–36 min | 环带转到另一侧，天空变空。星场成为主角，尘埃消光让部分星群变暗偏红。
期间**至少有一个悬空岛体**缓缓横过视野（岛群周期与进动周期不同，因此每次横过的高度与时机都不同） | 呼吸。留白，但仍有"岛在绕"的持续感 |

**硬性要求**：
- 环食**每个周期只发生一次**，不允许频繁。
- 环食的变暗**必须缓慢**（40～70 秒的淡入淡出）。任何瞬间的状态跳变都是失败的。
- 两个牧羊天体的公转周期**不能相同**，也不能成简单整数比（建议 1 : 1.37），
  这样多次环食的形态不会重复。

## 五、光与影的一致性（不可违反）

1. **全场只有一个方向性光源**：黑洞。环带、碎块、牧羊天体的受光面**全部**朝向黑洞方向。
2. 地形的**硬阴影方向必须与之一致**。若引擎限制导致无法做到，则宁可让末地地形阴影**极弱**
   （避免露出破绽），也不能出现"地形阴影朝一边、天体亮面朝另一边"。
3. 环食期间，除了全局变暗，**地形受光也应同步变暗**——这是"天体遮挡光源"的直接体现，
   也是玩家唯一能从地面感知到环存在的线索。
4. 黑洞**不与任何其他元素争夺亮度**。它是唯一允许过曝的元素。

## 六、色彩与分级

| 项 | 规格 |
|---|---|
| 黑位 | **必须黑得下去**。天空的暗部要达到近纯黑，不允许"灰雾感" |
| 高光 | 只允许黑洞的吸积盘与光子环接近过曝 |
| 对比 | 高。深黑 + 少量高光，中间调刻意压缩 |
| 冷色 | 环带基色、星场、暗部：偏冷的蓝灰 |
| 暖色 | **只有**黑洞周围 ±25° 的范围内允许出现暖色（`vec3(1.0, 0.78, 0.52)` 系） |
| 泛光 | 必须有，且要**收敛**——只作用于过曝区域，不能糊掉星点 |
| 暗角 | 有，极轻（边缘 -8% 亮度），用于把注意力收回中心 |
| 颗粒 | 有，极轻。作用是消除渐变里的色带，不是做"胶片感" |

**禁止**：全局的紫/粉色雾霭。这是之前被判定为"不真实"的直接原因——末地没有大气，
不该有任何形式的全场雾。

## 七、构图规则

这三条决定了"是否好看"，比任何单个元素都重要。

1. **黑洞与环带必须交错，不能重合。** 黑洞位于环带的**边缘附近**而不是环带中央。
   若二者共面，画面退化为一条带子中间一个点，毫无纵深。
   黑洞放大到 12° 之后，这条更容易被违反——**必须保证环带至少有一条完整边不被黑洞压住**。
2. **画面必须留出大片空白。** 环带占天空立体角的比例**不超过 25%**，
   黑洞周围的空区是刻意的。
3. **视线方向要允许"三种构图"都存在**：抬头看环带横跨、平视看环带在远方地平、
   转头看纯星场 + 黑洞。**不允许任何方向的视野是"空的什么都没有"或"满的喘不过气"**。

## 八、验收标准（可在游戏内逐条检查）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 静止观察 10 秒 | 除吸积盘湍流外，**察觉不到任何运动** |
| 2 | 观察 3 分钟 | 能看出环带在缓慢改变姿态 |
| 3 | 观察 10 分钟 | 能发现碎块之间的相对位移（剪切） |
| 4 | 环缝 | 边界锐利，可辨认出至少主环 + 卡西尼缝 + 恩克缝三段结构 |
| 5 | 环带外缘 | 柔和消隐，看不到"带的边界线" |
| 6 | 黑洞后方 | 能看到被引力透镜拉成的环带弧线 |
| 7 | 环食（约每 36 分钟一次） | 吸积盘被锐利暗带切断；全场缓慢变暗约 18%，持续 40～70 秒后恢复 |
| 8 | 星空 | 大星稀疏、暗星众多；位于环带之后的星变暗且偏红 |
| 9 | 任意位置（主岛 / 外岛 / 高空） | 天空表现**完全一致**，不随玩家位置变化 |
| 10 | 站在地面 | 地形受光方向与黑洞方向一致，环食时地形同步变暗 |
| 11 | 色彩 | 除黑洞周围外，**画面不出现任何暖色**；暗部接近纯黑，无灰雾 |
| 12 | 连续观察 40 分钟 | 环食形态**不完全重复**（两个牧羊天体周期不成简单整数比） |
| 13 | **黑洞尺寸** | 事件视界的视角直径达 **12°～13°**；抬头时占视野高度 **1/4 以上** |
| 14 | **盘的前后关系** | 能明确看到盘**近侧从阴影前方经过**、**远侧被顶到阴影上方**成弧 |
| 15 | **阴影内部** | 不是纯黑，能辨认出被透镜压缩的微弱星场 |
| 16 | **多普勒** | 盘的一侧明显亮于另一侧（约 3 倍），且一侧偏冷 |
| 17 | **悬空岛群** | 能辨认出岛形轮廓（平台 + 尖柱 + 收窄岛底），而非团块 |
| 18 | **逆光** | 黑洞位于岛体之后时，岛体成为纯剪影 |
| 19 | **两层运动可分辨** | 能分别看出"碎块沿环带流动"与"岛体各走各的轨道" |
