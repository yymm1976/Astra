# 依据 shader_research/SUMMARY.md 的优化实施（2026-10-02）

本轮依据用户指定的[二十包调研汇总](../shader_research/SUMMARY.md)，并回到相关单包报告阅读上下文，将适用的性能改动写入 `Astra/shaders/`。主世界优先；已有实现不重复记为新增，纯画质扩展不作为性能收益。

## 1. 公共参数继续移到 CPU

`shaders.properties` 新增以下公共表达式，`lib/uniforms.glsl` 提供对应接口：

- TAA 当前 / 前一帧八相位 Halton UV 偏移，保留原表和有限周期居中值；常用入口直接取 uniform，其它帧索引保留 GLSL 表接口。
- 云影缓存的世界坐标锚点，保留 192 格云层高度和 2 格对齐网格；读取端及写入端共享同一结果。
- 云影的实际日月光源高度曲线，以及雨湿响应、群系降雨 / 温度曲线。
- 主世界体积雾的海平面消光系数，包括质量之外的密度与天气倍率。

云影近地平线权重在光源高度 0.01–0.20 之间平滑增加，进入云透射缓存及边界外的解析退路；地形不再重复计算另一份高度曲线。低于有效高度时透射返回 1，避免低仰角直接变成全阴。雨天仍通过既有同源云密度响应，不另外乘一份湿度来改变积水或云色。

这些是帧内重复计算的转移，不是删除总计算量；CPU 已受限的场景收益会不同。属性端使用 `fmod` 和 `vec2`，依据 [Iris 自定义 uniform 文档](https://shaders.properties/current/reference/shadersproperties/custom_uniforms/)。

相关文件：`lib/taa_jitter.glsl`、`global/atmosphere/cloud_shadow_cache.glsl`、`program/cloud_shadow_cache.fsh`、`global/atmosphere/weather.glsl`、`program/scene.glsl`。

## 2. 阶段调度按实际贡献关闭

### 关闭 Bloom 时合并水下合成

此前根层 `composite3` 每帧读取并写回整张场景颜色，即使空气侧只是复制。现在仅在 BLOOM 开启时保留该阶段；关闭 Bloom 时，在原有显示阶段执行同一水下雾和光束合成，省去独立的全屏场景读写。

开启 Bloom 时继续维持“水下合成 → 水下 Bloom 捕获”的阶段顺序。关闭 Bloom 时，水下合成位于显示阶段的 Darkness、曝光及显示曲线之前；水下粒子继续在介质合成之后加入。TAA 水下路径仍拒绝场景历史。下界 / 末地保留各自的阶段覆盖。

### 无贡献空气光束

GODRAYS 强度为零，或被主世界体积雾替代时，不再因单独的 GODRAYS 开关保留 `composite2`。水下光束需要该阶段时仍保留。`colortex1` 的尺寸使用相同消费者条件，显示端也移除无贡献空气光束的读取。

水状态、透明层之前的场景副本和必要的水下介质处理仍有消费者，不能按 SSR 或光束开关一并停用。

相关文件：`shaders.properties`、`program/display.fsh`、`program/scattering.fsh`。

## 3. Bloom 捕获质量

新增 `BLOOM_QUALITY`，保持现有 1/4 尺寸捕获、HDR 阈值、过渡区、单源上限与四层 mip 合成。普通和水下捕获共用质量设置。

| 档位 | 每个捕获像素的场景颜色读取 | 过滤结构 |
|---|---|---|
| 低 | 4 | 四个双线性区域覆盖捕获纹素的源区域 |
| 均衡，默认 | 9 | 3×3 二项式权重，偏移匹配高档核的二阶矩 |
| 高 | 13 | 既有十三点过滤 |

默认捕获的场景读取由 13 次减少到 9 次。这里的数字不包含末地的深度与发光身份读取，也不是整包读取量或帧率变化。均衡档与高档具有相同的核二阶矩，但细小亮点的捕获和峰值可能不同；低档更容易漏掉小亮点。高档保留此前过滤结构。

四个画质预设分别指定低 / 低 / 均衡 / 高。低档预设原本关闭 Bloom，用户手动开启时使用低采样预算。新的低 / 均衡核由 Astra 编写，既有高档核及 prefilter 的来源声明继续适用。

相关文件：`global/post/bloom.glsl`、`lib/settings.glsl`、`shaders.properties`。

## 4. 短射线体积雾减步

新增 `VOLUME_FOG_ADAPTIVE`，默认开启；只在用户启用主世界体积雾时生效。质量设置指定步数上限，实际次数为 `min(质量上限, max(4, ceil(上限 × 射线长度 / 192)))`。

| 积分距离 | 低，最多 12 | 均衡，最多 24 | 高，最多 48 |
|---|---|---|---|
| 32 格 | 4 | 4 | 8 |
| 96 格 | 6 | 12 | 24 |
| 192 格 | 12 | 24 | 48 |

采样区间采用二次分布，近处更密；每段实际长度用于散射和消光积分，继续覆盖整个可见路径。透明层 / 水反射的前缀路径使用相同规则，并保留自己的 4 / 8 / 12 上限。透射低于 0.002 时结束步进；192 格之外仍沿用原有解析余段。

远处细光束与密度边缘可能更粗。关闭自适应后使用原质量的固定次数和均匀分段，透射早退仍生效。体积雾在四个预设中继续默认关闭。

相关文件：`global/atmosphere/volume_fog.glsl`、`lib/settings.glsl`。

## 5. 生电场景的实体投影开关

新增 `ENTITY_SHADOWS`，直接控制 Iris 的实体、玩家与方块实体阴影绘制名单，不通过片元 discard 来省工作。PERFORMANCE / NO_SHADOWS 关闭，BALANCED / ULTRA 开启。

关闭时这些对象不再投影，地形投影仍受 SHADOWS 控制；性能档实体阴影距离 32 格作为手动重新启用时的配置保留。这个开关是包级设置，并非只作用于主世界。

相关文件：`shaders.properties`、`program/shadow.vsh`、`lib/settings.glsl`。

## 6. 手持光、TAA 和可选夜间蓝移

手持光使用 `playerPos + relativeEyePosition` 计算相对于玩家头部的距离，第三人称不再以相机为光心。`relativeEyePosition` 的定义为相机减玩家头部，依据 [Iris 相机 / 玩家 uniform 文档](https://shaders.properties/current/reference/uniforms/camera/)。

连续距离曲线替换 15 格处的线性截断，仍复用现有第四次方的局部光消费者；源头在用户强度倍率之前限至 14/15。无发光物品或手持光强度为零时先返回零，不再计算每个片元到玩家的距离。双手较亮光源、天光压制及方块光合成继续使用现有接口。灯光近处及远处的亮度分布会变化，不单独将照明曲线的变化计作帧率收益。

TAA 增加历史纹素中心可信度：中心保持完整历史权重，靠近纹素边界时最多降低 35%。保留逐角点深度拒绝、反应遮罩、植被运动、状态有效期和现有 YCoCg 方差裁剪，不新增图像附件。

新增 `PURKINJE_STRENGTH`，以保线性亮度的独立混色实现主世界夜间暗部蓝移；明亮局部光源、夜视、水下及其它维度分别减弱或排除。默认 0，预处理移除颜色运算；质量预设不改该风格设置。开启会增加少量显示着色工作。

折射强度为零或法线偏移完全为零时，水上折射直接返回原 UV，省去两次深度 gather；水下零强度移除候选 UV 深度查询。正常折射继续使用候选深度判定及界面两侧处理。

相关文件：`global/lighting/blocklight.glsl`、`program/taa_resolve.fsh`、`global/post/grading.glsl`、`global/water/refraction.glsl`、`program/water.glsl`。

## 7. 汇总 Top10 对照与适用边界

| 汇总建议 | 当前落点 |
|---|---|
| 1. 程序级关闭 | 补齐 Bloom 关闭时的合成阶段、零强度 / 被体积雾替代的空气光束；原有体积雾 / SSR / 历史开关调度继续沿用 |
| 2. 手持光 | 已实现连续衰减、玩家光心、源头限幅 |
| 3. 云影与半影联动 | 已统一缓存 / 边界外场的光源高度淡出；Astra 现用 PCF，不为此新增 PCSS blocker 搜索及额外阴影读取 |
| 4. Purkinje | 已提供独立强度，默认关闭 |
| 5. 完全雾化 discard | 未采用：Astra 清屏颜色不保证等于雾色，且水体、AO、反射及透明层仍消费深度 / 材质；直接丢弃可能露出天空或破坏介质关系 |
| 6. 无阴影兜底 | 已有 `static_shadow(skylight)` 和 STATIC_SHADOW_FALLBACK，性能及无阴影预设已开启 |
| 7. 雨天波幅耦合 | 本轮未改：用户此前已明确原波幅正常，水下界面问题不应由降低或改变波幅处理；也不产生性能收益 |
| 8. 水下光束焦散 | 已有水面阴影生产焦散到 shadowcolor0，光束步进消费该透射；不再增加一份噪声焦散查询 |
| 9. 含云天空缓存 | `colortex11` 已烘焙完整球面天空与平面云，供水面、冰及积水退路使用，功能范围已覆盖单独“含云行” |
| 10. TAA 中心可信度 / 像素年龄 | 已补中心可信度。像素年龄未加入：现有 alpha 存储历史深度，不能直接替换；本轮不为收敛计数新增全尺寸附件 |

其它报告存疑项：Astra 已有稀疏积水、雨滴涟漪与湿材质响应，云步数已随云层穿越距离自适应，自动曝光已有中心加权及明暗亮度限幅，月相已有 CPU 参数。不能把这些重新当成缺失功能。水下主世界界面仍使用 Solas 派生的有界 Fresnel 关系，与 `optics.glsl` 的通用全反射分支不同；本轮没有改成新的物理水体模型。

下界体素跨帧累积、体雾和彩光联合、PCSS、场景 capture、TAAU、GI 与完整材质系统属于后续结构扩展；本轮围绕减少现有开销推进。报告摘要所称的“水体独立历史”不能套用到当前水面 SSR：该链路此前已退出渲染，当前独立历史为云、水下光束及下界反射等各自附件。

以上改动附有中英文选项说明及来源登记。范围为项目源码和文档；游戏加载表现、画面取舍及帧率变化尚未确认。
