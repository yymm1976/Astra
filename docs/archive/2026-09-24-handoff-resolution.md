# 交接清单处理记录

代码修改日期：2026-09-24；阴影与地表修订于 2026-09-25。当前未运行 Minecraft，下面不把离线算术结果写成实机观感结论。末地天空以外没有新增场景离线渲染器；新工具只执行当前 GLSL 函数，输入是人工构造的数据。

| 项目 | 已落到代码的处理 | 仍不能确认的部分 |
| --- | --- | --- |
| A1 水下焦散、光束 | 六列波不再使用等差频率；调整波长时保持各列曲率权重。折射相位使用 1/1.333。所有亮样本都有水体分色吸收；改用保持 RGB 比率的标量压缩，移除可能把三通道一起推向白色的幂函数。 | 焦散仍是小斜率聚焦代理，不是逆向光线密度求解；游戏内是否读成点阵、光束明暗是否合适，尚未观察。 |
| A2 下界岩 | 将当前 4.80 峰值、2.60 标量上限和方向权重提取到 `lib/surface_emission.glsl`；增加 `NETHERRACK_GLOW` 调节项。探针覆盖朝下、朝上、侧面和 RGB 峰值。默认 100 保持交接时强度。 | 没有熔岩湖上方岩面的实机画面，因此未再次猜测默认亮度。 |
| A3 末地石 | 材质编号 11 才产生微光。默认自发光 RGB 最大为 (0.16, 0.19, 0.08)，保留漫反射和纹理；通过末地 `colortex3.a` 单独传入泛光源，不要求表面跨过白色阈值。天空、其他方块、被透明几何覆盖的像素不进入该额外泛光路径。可用 `END_STONE_GLOW` 关闭或调节。 | 新微光的实际可见程度仍需游戏画面。 |
| A4 末地阴影横杠 | 修正深度偏移的方向：沿正光源方向偏移，避免原先沿负方向抵消法线偏移。保留已有斜率项，没有添加需要时间累计的抖动。 | 未观察实机条纹是否完全消失，不能仅凭偏移算术下结论。 |
| A5 黑洞晕动 | 保持当前 17.74° 角半径、0.0475 轨道速度系数及连续流场，修正文档。 | 没有新实机动态画面，未宣称眩晕问题解决。 |
| A6 倒角 | 9/25 修订：移除按 `fract(worldPos)` 扰动法线的整层格线倒角及额外阴影查询。末地石、黑曜石保留原材质法线与 GGX 高光，离线预览同步使用该路径。 | 真正只作用于外轮廓的倒角尚未实现；此前降低强度、缩小范围仍不能避免内部共面接缝。 |
| B1 顶点 AO | 开启 Iris `separateAo`，地形 AO 用独立 varying 传递，不再充当透明度；主世界、末地保留原有 RGB AO，下界消费独立 AO。真实零值不会再被当成“无数据”改成 1。`DEBUG_VERTEX_AO=1` 直接显示地形 AO，并绕过后处理。 | 尚未获取游戏里的顶点 alpha 数值。观察时需保持 `SHADOWS` 开启；白色表示 AO=1。关闭阴影时按 Iris 的限制恢复 RGB AO 路径。 |
| B2 阴影边界 | 恢复扭曲投影设计所需的 `shadowDistanceRenderMul=1.5`；实体距离比例表明确对应 `ENTITY_SHADOW_DISTANCE/(1.5*SHADOW_DISTANCE)`。 | 240–256 格、低太阳角下的收口仍需游戏场景确认。 |
| B3 银河层 | 删除几乎不可见的银河层及 GUI、档位、语言文件中的 `END_NEBULA`。星点透镜保留。 | 没有重新引入被否决的彩色片状天空。 |
| B4 硬件阴影 | 表面路径逐纹素配对深度比较与投射材质颜色；9/25 将每波瓣四次逐纹素 `texture` 改为一次 shadow `textureGather`，保留四角独立比较结果。默认仍为软件模式，语言提示改为说明两者的实际区别。 | 不能由调用数推导整帧性能倍率，也没有把硬件选项宣传为必然更快。 |
| B5 水体合成 | 空气像素继续显式写回颜色，并在代码中说明 Iris 双缓冲交换的原因。 | `discard` 不具有保留当前输入缓冲的语义，故不采用这一优化。 |
| C1 水下工具 | 重建两个入口，均直接编译和执行当前焦散、光束函数；同时读取当前水面吸收函数。报告有限性、相位、颜色、动画及频域信息，不将纹理分布宣称为视觉验收。 | 没有模拟真实世界遮挡、Iris 全链路或相机运动。 |
| C2 岩石工具 | 重建为调用当前材质函数的 GPU 探针，去掉对历史提交和不相关选项文件的等同性要求。旧入口 `block_reflect_gates.py` 指向同一个探针。 | 输出是附加光的数值，不是完整成像亮度。 |
| C3 版本管理 | 使用 `codex/fix-render-handoff` 集成分支，提交可运行光影所需源码、原创纹理、文档和工具；已有渲染输出留在本地。实例中实际存在五个 `Astra-backup-*` 目录，已移到同一实例的 `Astra-retired-shaderpacks`。 | 递归删除被自动审批阻止，因此采用保留内容的移动方式。不把历史截图当作当前版本画面。 |
| C4 文档 | 末地文档更新半径、动画、银河移除、末地石发光机制；旧图片明确标为历史预览。 | 图片没有重新拍摄。 |
| C5 失效代码 | 删除 `astra_water_air_sky`、旧尘环渲染器和失效的 `end_march_count.py`。9/25 补删此前遗漏的 `ShadowTap`、`shadow_read_tap`、两处 `SHADOW_FILTER_TAPS` 及 `shadow_filter_uv`；这些阴影抽象没有活动调用者。 | 原记录只完成了列出的旧代码删除，遗漏阴影脚手架，不应据此宣称包内失效代码已全部清理。`end_ring_axis` 仍用于有效几何布局。 |
| C6 性能 | 新增 `NO_SHADOWS` 档位；`SHADOWS=off` 显式设置 `shadow.enabled=false`，同时停止下界体素写入、传播及消费。云步进先裁到可见水平范围，并修复首次采样的 xz/y 不一致。 | deferred 的全分辨率双输出仍保留；水体即使关闭屏幕空间反射、折射，也依赖未加雾的场景背景。移除它需要改变缓冲读写职责和后续透明渲染，不能直接删掉写入。云的最坏上限仍为 64 步；未取得实际帧时间。 |

驱动编译记录：默认 BALANCED、硬件阴影、关闭阴影分别链接 90 个程序，失败均为 0；三个档位的地形 AO 显示分支共链接 9 个程序，失败为 0。硬件与软件过滤在混合材质人工样本中逐通道最大差异为 0。编译器会编译被配置禁用的入口，这里的计算程序计数不代表运行时仍有 dispatch。
