## 1. 本轮实际实现：T1–T3

设置入口：**后处理 → 抗锯齿 → TAA（可选）**。`ANTIALIASING` 为 0 关闭、1 FXAA、2 TAA；PERFORMANCE / NO_SHADOWS 为 0，BALANCED / ULTRA 为 1，TAA 首版手动开启。抗锯齿为本包新增的三选一设置，不存在被迁移的旧 FXAA 选项。AO 调试显示关闭投影抖动和 TAA 阶段。

### 坐标与阶段

`lib/taa_jitter.glsl` 提供去除有限序列均值的八相位 Halton (2,3) 抖动，以全分辨率像素为单位。`program/lit.vsh` 给主视图几何加入抖动；阴影投影不变。`screen_view` 扣除偏移，`view_screen` 加回偏移；SSR 的直接投影与深度重建、折射、光源屏幕坐标一并接入。屏幕云和天空通过同一重建接口获得射线；球面环境图与世界云影图继续使用各自坐标。

| 阶段 | 行为 |
|---|---|
| gbuffers | 写场景颜色；TAA 开启时写 colortex16 动态遮罩及 colortex22 植被运动 |
| deferred | 合成云等可见大气，并把云覆盖 / 动态天空加入遮罩 |
| composite5 | 延续自动曝光计量，输入当前帧原场景 |
| composite6 | TAA：读取当前场景、深度、遮罩、上一帧颜色与状态；输出稳定网格的 HDR 场景及新历史 |
| composite7 | TAA：写入本帧 3×1 状态，供下一帧使用 |
| composite8 | 仅 FXAA：组装显示颜色与亮度，写 colortex13 |
| final | FXAA 模式做空间 AA；TAA / 关闭模式直接组装显示画面；最终输出抖动在显示变换之后 |

根目录、`world-1`、`world1` 均有相同阶段入口。TAA 历史采用未抖动的输出网格，因此前帧投影不再加前帧抖动；当前输入在带抖动坐标上做双线性重建。显示阶段对尚未解析的深度、Bloom 和光束也使用对应的当前帧坐标。

Bloom、空气光束和最终水下粒子在 TAA 之后合成，不计入 HDR 历史。显示变换、自动曝光增益和最终输出抖动不反馈进历史；不能把此实现描述成所有效果都经过时域处理。

### 历史资源

| 缓冲 | 格式 / 尺寸 | 内容与生命周期 |
|---|---|---|
| colortex15 | RGBA16F，全分辨率 | RGB 为 HDR 历史，A 为 log2(1+视空间深度)；0 代表天空，-1 禁止复用；跨帧保留 |
| colortex16 | R8，默认全分辨率 | 当前帧动态程度；逐帧清零。启用时不设 size.buffer 覆盖，使 gbuffers 可写入 |
| colortex17 | RGBA32F，3×1 | 帧号、视口、介质、维度标记、光照 / 黑暗状态与时间；跨帧保留 |
| colortex22 | RGBA16F，默认全分辨率 | RG 为植被到前帧的 UV 位移，B 为前帧预期对数深度，A 为有效性；逐帧清零 |

1080p 下上述四个缓冲的双纹理有效存储合计约 **67.24 MiB**，其中植被运动新增约 31.64 MiB；不含驱动开销。TAA 关闭时将这些资源缩为 1×1，并停用 composite6/7；TAA 模式不启用 FXAA 的全分辨率 colortex13。使用目标实例 Iris 1.11.2 的扩展 ColorTex 索引。

### T2：有效性与颜色约束

- 前帧序号必须连续，视口、介质及标准三维度标记必须一致；首帧和重新载入时拒绝旧内容。
- 相机单帧位移超过 8 格、旋转超过约 60°、投影矩阵变化、帧时间间隔超过 0.25 秒、失明 / 黑暗 / 闪电状态突变时清空历史贡献。
- 静态几何使用前帧模型视图、投影及相机位移；天空只使用方向变换，不套相机平移。
- 越界与相机后方直接拒绝；四个双线性历史贡献分别比较对数深度，再混合有效颜色，避免先混出不存在的中间深度。
- 深度容差含有界斜率补偿；YCoCg 的 3×3 范围与方差共同约束历史；较大运动和亮度突变降低历史权重。

### T3：保守动态路径与未实现部分

水 / 冰 / 玻璃等特殊材质、积水、实体、方块实体、手持物、粒子、雨雪、透明层、可见云及末地动态天空标记为当前帧区域。植被仅在前帧状态和投影有效时允许累积；无效时走相同保守路径。遮罩独立关闭混合，避免透明颜色的 alpha 把分类冲淡；解析时扩展一像素覆盖边缘与采样范围。被隔离的动态像素向历史写入 -1 深度，移开以后背景也不会复用这些旧像素。下界烟雾使用较低历史权重；水下整体使用当前帧。

**当前限制：尚无实体运动矢量或水云专用运动场。** 植被已接入前帧形变，细节见第 6 节；其余上述动态区域只做当前帧重建。双线性重建可能柔化纹理；深度阈值和颜色约束是初始参数。

主要文件：`lib/taa_jitter.glsl`、`lib/taa_reactive.glsl`、`lib/taa_state.glsl`、`program/taa_resolve.fsh`、`program/taa_state.fsh`，以及 `lit`、`unlit`、`deferred`、`display` 和三维度薄入口的接入。

## 3. 高画质功能的当前边界

### H1：方向性天光（首版代码完成）

已从当前天空辐射按方向与立体角积分，形成九个 RGB SH 系数，按表面法线求漫反射天光。云关闭时直接采样纯天空。保留洞穴、夜视和 SKYLIGHT_STRENGTH 语义；不把日月圆盘计入天光。独立开关，不依赖 TAA。当前为全局天空方向响应，无局部遮挡方向或几何反弹光。

实际入口：`prepare3` / `program/sky_irradiance.fsh` → colortex18 → `lib/sky_directional.glsl` → `global/lighting/diffuse.glsl`。

### H2：AO、bent normal 与环境光合成

已拆出可遮蔽环境贡献，采用半分辨率标量 AO、深度 / 法线保边合成；不直接乘整张场景。顶点 AO 与 SSAO 取较暗的一项，直射、局部光、发光独立。首版限主世界空气侧的普通不透明地形，要求开启实时阴影以取得独立顶点 AO；不依赖 TAA。**bent normal 仍未实现**，见 R1。

### H3：主世界体积雾

增加有界距离、低分辨率的世界射线积分，输出散射 S 与透射 T，用 scene×T+S 合成。包括高度密度、地形阴影、云影和日月 / 天空入射。与现有距离雾共用或替代同一段消光，整合 GODRAYS 和 rainy_air 的重复散射；水下介质保持独立。云、透明层和水界面需按前后关系处理；colortex4 继续承担未施加观察介质的场景，不能重复消光。首版手动开启，不包含局部烟雾体或多次散射 GI。

### B4：下界彩光布局

现有捕获使用 R32UI 原子写入，传播使用两个 RGBA16F 的 64³ 体积，在同一帧进行九阶段计算。需要依据存活资源、格式与邻域依赖选择压缩或调度方案；工作组之间没有可依赖的全局同步，不能把多阶段传播直接塞成一次 dispatch。S3 已集中坐标与范围约定；存储格式、原子写入和传播算法尚未改变。

### H1 实际实现

`prepare3` 在主世界几何之前写入 9×1 RGBA16F。每个系数用 8 个均匀 y 分层和 16 个方位角积分，共 128 个等立体角方向，权重总和为 4π。开平面云时读取已生产的 colortex11；关云时直接求天空辐射，天空渐变的采样扰动固定。下半球使用镜像上半球辐射的 8%，只是美术补光。

`sky_directional.glsl` 保留有符号系数，在漫反射求值之后才截除负结果；按零阶均值归一化方向响应，由当前天空环境调色控制曝光，方向倍率有界。`diffuse.glsl` 的天光项消费结果，不额外再乘旧的面向系数；洞穴最低亮度仍沿用旧面向规则，夜视平滑回到原模型。水下、下界、末地不使用此路径，启用透光的植被与玻璃保留专用光照。

菜单：光照 → 方向性天光，默认及四档预设均关闭。它不依赖实时阴影、平面云或 TAA。此项不是 GI，也没有 bent normal。

### H2 实际实现

`diffuse_lighting` / `astra_light` 新增 `ambientRadiance` 输出，在加入局部光之前记录环境分项，并使用与最终表面一致的夜间去饱和颜色。几何阶段把未遮蔽环境 RGB 与顶点可见度写入 colortex19，把真正的几何法线与有效标记写入 colortex20；colortex3 的积水法线用途不变。

启用 AO 时，符合条件的地形不再把顶点 AO 预乘进 sRGB 顶点颜色，而是在光照后仅遮蔽线性环境分项。这意味着开启此功能也会改变原顶点 AO 对直射和局部光的影响，是有意的环境光分离。未参与的植被、发光类、水、冰、玻璃、实体、手持物和透明层保留原路径。破坏裂纹层显式保留原顶点着色，同时清除该处的 AO 接收标记。

根目录 `deferred` 在 AO 开启时生产半分辨率 AO：2×2 输入中选择最近的有效几何像素，12 个固定角度与半径样本，有界世界半径、距离权重和角度偏移。结果同时保存选中像素的对数深度和几何法线。新增 `deferred2` 接回原有场景处理，按深度 / 法线筛选四邻域后，只扣除额外被遮蔽的环境贡献，使最终环境可见度等于 `min(vertexAO, SSAO)`。合成位于观察介质与积水反射之前，colortex4 保存处理后的未施加观察介质场景。

菜单：光照 → 环境光接触遮蔽（屏幕空间 AO），强度默认 75，半径默认 100（1 格）；默认及四档预设均关闭。**首版要求实时阴影开启**：当前包只有此时启用 Iris 的独立顶点 AO 输入。AO 不依赖 TAA，限主世界空气侧普通不透明地形；没有 AO 历史或 bent normal。屏幕外遮挡不可见，轮廓无相近深度 / 法线样本时返回无遮挡。

### T3 植被实际实现

colortex17 的第三像素改为 `(维度标记, 前帧雨量, 前帧摇曳强度比例, 版本 2)`，第二像素继续保存真实前帧时间。当前顶点形变之前，用同一未形变世界位置、相同叶片 / 草顶分类和保存的参数求前帧形变，加上相机位移，再投影到未抖动的历史坐标。

`lit.fsh` 把前帧 UV 相对于当前未抖动 UV 的位移、预期前帧对数深度及有效标记写入 colortex22。`taa_resolve.fsh` 对有效植被使用这组位移 / 深度，继续执行历史深度拒绝、邻域约束和动态遮罩扩展。首帧、状态中断、越界、位于相机后方时不开放累积；摇曳关闭时按静态植被位置处理。当前顶点和阴影形变仍走原接口。

此项随 TAA 启用，没有新增独立选项。实体、水、云仍保守隔离，不能据植被运动链推断它们已经得到时域处理；植被的光照突变仍依靠现有颜色约束控制。
