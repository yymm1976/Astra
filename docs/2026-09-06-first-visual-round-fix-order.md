## P0-1 天空错误阴暗（正午 11:17 应为明亮蔚蓝）——上游问题，优先修

**现象**：天顶深灰蓝，大块暗色板状云覆盖半个天空。BALANCED 档 `CLOUD_MODE=0`（原版云），所以暗色板状云是**被我们管线渲染的原版云**。

**两个子假设（按此顺序排除）**：
1. **原版云被染黑**：E1 的云 pass（`program/clouds.fsh`）或雾色混入把原版白云压暗。验证：`/gamerule doWeatherCycle false` + `/weather clear` 后看云；或临时把 `clouds` 渲染关闭对比。
2. **Minishita 天顶亮度/太阳角映射错误**：`sky_minishita.glsl`（D2）输出的天顶色在正午应接近亮蓝，当前接近暮色深蓝。验证：`/time set 6000` 与 `/time set 13000` 各截一张——若两张差异不大或正午偏暗，则是太阳角/时间映射（查 `worldSunVector`、`sunAngle` 的 custom uniform 链与 D2 的输入约定）。

**修复**：D2（sky_minishita/云亮度）；若定位到 CPU 侧参数则归 Z3。
**验收**：同机位重拍，正午天空亮度/色相应与 Steadfast #12 的天空档位相当。

## P0-2 远处山体错误透明

**现象**：远山呈幽灵状半透明，暗云板与山体重叠处尤其明显。

**三个假设（按此顺序排除）**：
1. **雾色跟随暗天空**（B2 fog）：雾把远山混向暗色，叠加亮云背景后读作"透明"。→ 先修 P0-1，复测。
2. **原版云与地形的深度/混合**：暗云板画在远山之上且无深度交互（E1 云 pass 的 blend/depth 状态）。验证：飞到云高度看云与山的前后关系；临时 `clouds=off` 对比。
3. **预乘 alpha 链泄漏**（E2 deferred 副本/透明混合 `ONE, ONE_MINUS_SRC_ALPHA`）影响不透明几何。验证：把 FANCY_TRANSLUCENTS 关闭对比远山。

**修复**：按定位结果分别归 E1（云 pass 状态）/ B2（雾色）/ E2（混合链）。
**验收**：远山不透明、轮廓清晰，与 #12 的远山表现相当。

## P1-3 水体深青、显脏（依赖 P0-1）

**现象**：水面深青发暗、法线细节杂乱显脏；近岸浅水有块状亮斑（折射/浅水伪影，次要观察项）。

**原因链（上游 → 本地）**：
1. **反射源 = 暗天空**：天空修好前水面必然暗——P0-1 先行；
2. **表面吸收/色调偏强**：`WATER_ABSORPTION=100` 下浅视角度也偏深青，`absorption.glsl` 的表面色调与 `waterCharacter` 曲线需对 Solas 口径放宽（Solas 观感=清而不灰）；
3. **波法线高频噪声**（C7 新换的 Steadfast 波场）：噪声尺度/频率与 roughness 下限失配 → "脏"。降波幅、抬 roughness 下限、检查 `WATER_WAVE_HEIGHT/SPEED` 的消费缩放。

**修复**：C2（吸收曲线/表面色调）+ C7（波场参数）；数值调整全部走 `grading`/模块常量，不动接口。
**验收**：对照 #12——水面亮度、清透度、反射中的天空颜色相当；近岸无块状亮斑。

## P1-4 水下氛围阴暗 + 粒子突兀（对照 08/09 Solas 参考）

**现象**：水下整体过暗（天光 11 时近乎暮色），悬浮颗粒=稀疏白色小点，突兀。

**修复**：
1. `absorption.glsl` 吸收曲线放缓 + 水下环境光随 skylight 抬升（Solas 水下是"清亮的蓝"，不是"暮色的深青"）；
2. `underwaterFog` 密度/颜色提亮（`UNDERWATER_FOG_DENSITY` 消费端）;
3. `particles.glsl`：降低亮度与 shimmer 幅度、缩小粒径、提高密度但降低对比、随距离被水色吸收吞掉（现在是"近处突兀的白点"而非"柔和微尘"）。常量集中在该文件头部（PARTICLE_SHELLS/SHIMMER 等）。

**验收**：对照 `08/09-reference-solas-underwater`——亮度、通透度、颗粒存在感相当；用户目视过关。

## P2-5 帧率：140 → 目标 ≥144（流畅档）且消跳动

- 140 vs 166 差距 ~13%：P0/P1 修复后云层与雾路径成本会变化，**先修画面再测帧率**；
- 跳动源排查顺序：粒子逐帧循环（particles.glsl 的 for 壳层）→ planar/原版云 pass → 首次编译 hitching（与均值无关，注明即可）；
- 正式调档归 E3（顶级Ⅱ 恢复后），本轮只要求消除异常卡顿源、达到"均值 ≥144、无明显跳动"的过渡目标。
