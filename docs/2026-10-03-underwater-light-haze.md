# 2026-10-03 水下轻雾调整

本页记录第一次轻雾调整。用户随后提供 Astra、Solas、ITT 3.2 三张游戏截图，明确指出这版雾气不明显、暗部过重，并要求青色水体、光束明暗变化及 ITT 风格焦散。现行代码已按这些反馈重做，见[水下风格调整](2026-10-03-underwater-itt-style.md)；下文旧参数不再代表当前实现。

用户希望水下有一点雾气，但不过浓，喜欢 ITT 3.2 和 Solas 的水下风格；随后明确要求先完成代码，再请求其进入游戏观察。本轮按这一顺序处理。

## 参考与实现

读取本地 IterationT 3.2.0 的 `shaders/composite1.fsh::WaterFog` 和 Solas V2.2b 的 `shaders/lib/water/waterFog.glsl`。ITT 将距离雾、颜色衰减和方向性散射分别计算；Solas 使用随距离增长的指数雾，雾色受天气、环境光和迎光方向影响。ITT 的默认水下距离雾是 `exp2(-d*0.04)`，Solas 的默认响应是 `exp(-d*0.06)`，两者合成域与其他水下处理不同，不能仅凭系数比较最终画面浓度。

Astra 保留现有 Solas 蓝青色、天气与日夜响应，以及先在平方根域混雾、再加入光束的合成顺序。新的距离响应为：

```glsl
float waterDistance = length(viewPos);
float hazeDistance = waterDistance * (waterDistance / (waterDistance + 12.0));
float density = UNDERWATER_FOG_DENSITY * 0.000375;
float fogAmount = 1.0 - exp(-hazeDistance * density);
```

`d*d/(d+12)` 在眼前从零平滑增长，没有突然开始起雾的距离分界；远距离与真实距离的比例趋于 1。默认 40 时远距离消光系数为每格 0.015，比此前每格 0.020 更轻，同时进一步减弱近处雾感。下面是公式推导出的混合权重，属于着色器合成参数，不能当作画面亮度或实际可见距离：

| 视线距离（格） | 此前权重 | 新权重 |
|---|---|---|
| 8 | 0.148 | 0.047 |
| 16 | 0.274 | 0.128 |
| 32 | 0.473 | 0.295 |
| 64 | 0.722 | 0.554 |
| 96 | 0.853 | 0.722 |

四个画质档继续使用默认浓度 40。现有滑块按比例调节雾密度，菜单说明改为“默认轻雾”，修正此前误写成 Solas 默认浓度的源码注释。

## 消费路径与开销

调整位于共享 `solas_water_fog`：Bloom 生效时由 `program/water_composite.fsh` 调用，Bloom 不生效时由 `program/display.fsh` 调用，仍各自只施加一次。没有另加水下颜色吸收或距离雾层；水面、焦散、光束、显示曲线及反射查询沿用现有实现。

距离计算仍使用一个 `length` 和一个 `exp`，新增近处过渡的标量加法、除法与乘法；没有新增纹理读取、附件或循环。此调整针对雾感，上一轮已记录的水面 SSR 命中细纹仍是独立的画面事项。

## 用户进入游戏后的观察

重载 Astra，先保持水下雾浓度 40。在晴天浅水中观察近处海草、砂石和焦散，再水平看向较远的海底；目标是近处有清楚细节，远处逐渐融入淡蓝青色水雾。面向太阳及背向太阳各看一次，再进入深水或夜间观察暗处是否仍有层次。
