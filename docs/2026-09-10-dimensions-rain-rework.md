# 下界、末地与雨天：画面问题与本轮改动

## 症状到代码的链条

### 下界流动斑块与群系失色

旧 nether_fog 将物体表面世界坐标送入 nether_cloud_glow，噪声随时间移动，再把结果直接叠加进该表面的雾色。它没有沿观察射线积分，因而显示为附着在地形上的流动斑块。换光照系数不会修复这条路径。

旧 nether_atmosphere_tint 将群系颜色线性化、归一化后两次开方；暗色通道被抬高，色差缩小。下界光照、天空与雾还使用了不同变换。此轮删除端点噪声，雾/天空/照明统一读取群系配色，接入独立平滑群系权重。沿用 Complementary r5.9 模式 3：荒地橙红、绯红森林暗红、诡异森林紫色、玄武岩三角洲灰褐、灵魂沙峡谷青色；跨群系渐变约八秒。

### 末地黑顶、地形过暗、无影子

原版天空几何并不保证覆盖全部屏幕，旧 deferred 对无地形像素直接保留原颜色，缺失区域因此没有补齐。现在在 deferred 用深度识别背景，全屏重建观察方向并绘制末地天空；恒星与星空不再依赖原版天空三角形的覆盖。

world1/shadow.enabled 原为 false，end_lighting 也不采样阴影，原来的方向明暗不是遮挡阴影。现在开启末地阴影，地形使用实际阴影深度；发光恒星和地形受光共用 lightVector 的世界方向。

旧近景虚空雾在三十余格后已覆盖约 55% 场景，再叠加低环境光与紫色调色，主岛变暗。改为 Solas 随视距四次方增长的远雾，去除近景 55% 覆盖，并提高地形可读性。

旧星云是普通噪声的两层阈值配色。现在使用 Solas skyEffects 的星空分布、螺旋星云公式及其原噪声纹理；不绘制末地大气云。新增可见的亮恒星及光晕，保留 HDR 发光供泛光使用。恒星外形与地形亮度属于 Astra 的适配，不声称整个 Solas 画面逐像素相同。

## 雨天逐项实现

| 要求 | 实现位置与行为 |
| --- | --- |
| 云更多 | clouds_planar + weather：降低雨天云形成阈值，雨量平滑变化；原云模式在降雨时也叠加程序云 |
| 阳光更弱、阴影更浅 | overworld + scene：满雨直射降到晴天的 22%，并按云层位置削弱；保留漫射天光，减少明暗反差 |
| 雾更多 | fog：室外增加随距离累计的雨雾；洞穴和水下有独立限制 |
| 透明雨滴 | lit：温暖群系降雨采用程序生成的中性透明滴形，替代原版蓝色纹理；寒冷群系保留雪花；显式输出透明度 |
| 积水 | weather + lit：露天朝上的普通地形，根据湿度和世界坐标噪声分布形成积水；材质变湿变暗，随湿度消退干燥 |
| 雨滴落水圆环 | weather：不同位置、不同相位的扩散圆环扰动积水法线 |
| 积水倒影 | deferred：Fresnel 混合天空/云与屏幕内景物反射；屏幕外景物不能由这条路径恢复，使用天空补足；关闭屏幕反射的性能档仅保留天空倒影 |
| 太阳藏云、浅光束 | sky + deferred：太阳盘按同一云场透射衰减；空气中的短步进同时读取云遮挡和地形阴影，朝太阳方向保留弱散射 |

本轮没有改变已经确认修好的主世界阴影投射/透明叶片处理，也没有再次修改水波纹理、波幅或折射逻辑。

## 交付范围

PERFORMANCE / BALANCED / ULTRA 共 234 组 OpenGL 程序编译链接成功。同步到现有整合包的 Astra。编译结果不代替游戏画面的确认；新视觉效果尚未在本轮实际游戏画面中确认。
