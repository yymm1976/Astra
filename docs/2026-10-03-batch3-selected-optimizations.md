# 2026-10-03 SUMMARY-batch3 选择与实现

根据 [SUMMARY-batch3](../shader_research/SUMMARY-batch3.md) 与当前源码挑选改动。用户此前报告同一沙滩场景约 100 帧；此次优先保留已经恢复的花草投影、浅水／流水颜色衔接与水下效果。报告的“未实现”判断只代表调研时的判断，接线前仍需确认当前路径。

## 已采用

| 项目 | 当前实现 | 画面与开销边界 |
|---|---|---|
| 植被风场距离 LOD | `global/lighting/wind.glsl` 新增共享距离权重。128 格以内保持原幅度；128–192 格按距离平方平滑渐弱，192 格外跳过位移求值。`program/lit.vsh` 历史位移使用上一帧摄像机相对位置的权重，模型和投影使用当前帧权重。 | 保留植物投影，近处运动保持原样；远处摇曳幅度减少。渐弱区仍计算波形，停止区才省去四个空间相关正弦；当前与历史顶点都可受益。没有采用天光幅度调制。 |
| TAA 反应遮罩邻域 gather | `program/taa_resolve.fsh` 内部像素采用两次 2×2 gather，加上两个未覆盖角点的点读取；边界保持原有逐点裁剪。中心达到拒绝阈值后仍直接返回，后续读取也按阈值停止。 | 完整覆盖原有 3×3 最大值范围。内部未提前退出时，由九条纹理读取指令改为五条；返回的纹素分量有重复，不能把指令减少等同于带宽减少。仅选择 TAA 时生效。颜色统计、逐角历史深度拒绝、权重与水下历史禁用保持原处理。 |
| 云层白天调色帧级计算 | `shaders.properties` 新增 `astraCloudDayLight` 与 `astraCloudDayAmbient`，`lib/uniforms.glsl` 声明，`clouds_planar.glsl` 消费。移走白天光色的三个分量幂运算及白天环境色混合。 | 使用已有时间曲线、原有系数和混合顺序。夜间／雨天混合、屏幕亮度、晨昏艺术调色、云密度、步数和历史均维持原处理。屏幕云、反射环境和局部云查询共享这些帧级结果；未新增阶段或纹理。 |

TAA 元数据版本由 3 调整为 4，读写同步更新。历史植物位移必须使用上一帧的距离衰减，不能把当前帧权重用于旧摄像机，也不能继续接受采用旧位移规则的元数据。

## 对报告结论的纠正

- Bloop `MinDepth3x3` 所列三次 gather 的偏移为 `(-1,-1)`、`(0,-1)`、`(-1,0)`，共同覆盖八个不同纹素，缺少右上角 `(1,1)`，并非完整九点。Astra 仅参考分量聚合的思路，自行覆盖全部九点；不照搬该函数，也不把 RGB 三通道统计直接替换为更多 gather。
- 当前 `program/shadow.vsh` 已有材质级提前退出，且上一轮刚恢复小植物投影。报告的“无材质级投射剔除”不符合当前入口；继续排除花草与用户反馈冲突。
- 当前 `program/scattering.fsh` 已在单像素内聚合太阳遮挡并广播，采用的是已有 7×7 探针，不再添加另一套太阳探针或占用曝光记录。
- 当前体积雾源只查询 `shadow_opaque_visibility`，没有每步无条件读取 `shadowcolor0`。已有覆盖门控继续使用，报告建议的彩色阴影读取裁减在此路径没有目标。
- 当前水面焦散已记录在 `shadowcolor0` 的水面高度／光学斜率／聚光数据中，接收面复用记录。再加焦散烘焙附件不属于补齐缺失实现。
- 水反射历史模块处于停用状态；其旧槽位 28／29 已分别用于下界反射元数据和水下光束。报告中按活动水反射历史裁减读写的建议没有对应消费链，不能直接恢复旧模块或复用槽位。

## 本轮暂缓

| 方案 | 选择理由 |
|---|---|
| 15 格 AO 截止、远处阴影降采样 | 固定短距离截止容易出现明暗跳变；AO 当前默认关闭。此次保留既有接触遮蔽与阴影过滤预算。 |
| 失明／夜间满雨时跳过云 | 当前失明压低云 RGB，云 alpha 仍负责遮挡；夜间雨云也有非零亮度。透明早退会改变遮挡和轮廓，不能仅凭“不可见”判断移植。 |
| 四类背面剔除、关闭原版水下叠加 | 双面水界面和半透明内部显示依赖几何覆盖；此轮刚修正流水内部，未改变管线开关。 |
| sRGB／雾函数近似 | 会改变色域、灰阶或水色，而收益没有可靠依据。保留现有编码和雾公式。 |
| 波高预计算图、低分天空新附件 | 当前已有解析光学场、水面阴影记录和反射环境缓存。新增阶段有额外成本，本轮未扩大资源链。 |
| 低分反射、上帧 SSR、TAA_FAST、TAAU | 涉及颜色／深度／界面坐标与历史契约，或改变纹理清晰度。保留当前水路配对与完整历史拒绝规则。 |
| 1spp 体积光、随机噪声替换、分帧体素更新 | 用户先前反馈过严重水下噪点；下界体素当前使用每帧清空及完整传播，跳写目标或停调度不能直接保证有效内容。此次未引入这些时域取舍。 |
| 雨条云上裁剪、CAS、隔离显示、CSM／光箱／GI | 属行为变化、额外画质功能或较大的架构工作，与此次保留画面并裁减重复工作的目标不一致。 |

## 出处与状态

Potato 的距离门控、Bloop 的单通道邻域 gather、Builder's QOL 的帧量上提只作机制参考；本轮门控、覆盖和接线由 Astra 编写，没有复制这些参考包的实现片段或新增素材。云白天调色只是将既有 Complementary 衍生公式改到 CPU 求值，其来源与许可归属继续适用，登记于 `Astra/THIRD-PARTY.md`。

已逐处阅读新增 uniform 与消费者、植被当前／投影／历史入口、TAA 邻域覆盖与元数据版本关系。源码及说明已同步到实例包；本轮没有新的游戏画面或帧率反馈，不宣称已达到额外帧率提升。风场收益取决于远处植被数量，TAA 收益取决于是否启用；CPU 调色的收益取决于命中云的像素量。
