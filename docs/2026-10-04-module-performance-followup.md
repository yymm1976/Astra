# 2026-10-04 各模块性能审查接续

本轮围绕当前 Astra 的三维度渲染实现审查开销，并直接修复重复求值和无贡献读取。现行源码及实际消费者决定改动范围，历史文档仅用于理解已有实现。

## 已实施的修复

| 模块 | 位置与改动 | 画面及开销范围 |
|---|---|---|
| 水体反射与折射 | `program/water.glsl`：最近纹素的介质处理结果由中心足迹、宽反射足迹中的同纹素角点及备用路径共享 | 复用相同颜色、深度、界面方向和入射光下的吸收／散射；其他角点仍分别处理，保留全部足迹及其原权重。主要减少宽反射足迹重复命中最近纹素时的指数和水色运算 |
| 平面云 | `global/atmosphere/clouds_planar.glsl`：遇到云之后才求日光方向点积；晨昏权重为零时跳过冷暖边缘调色 | 密度读取、首个命中、云照明查询、云色与天空融合以及历史代表位置保留；晨昏时仍执行完整原公式 |
| 地表昼夜光照 | `global/lighting/diffuse.glsl`：夜间权重、天光或局部光保护权重为零时，夜间去饱和直接返回零 | 白天和被局部光完整保护的材质保持原色，省去不参与结果的阴影颜色亮度计算；非零夜间处理沿用原曲线 |
| 主世界场景、AO与手持物 | `program/deferred.fsh`：先取得材质标志并修正手持物投影，再进行一次视空间重建；地形 AO、介质与体积雾共用结果 | 手持物不具备 AO 接收资格，直接跳过该查询；地形沿用原深度与投影，手持物沿用原 `MC_HAND_DEPTH` 修正 |
| 可选体积雾重建 | `global/atmosphere/volume_fog.glsl`：接收调用方已求出的视深度；深度带权重为零的角点在读取材质之前退出 | 四角重建、0.02–0.06 相对深度带、手持物拒绝、权重归一化及无匹配角点时的前缀积分保留。手持物角点现在先求深度带再拒绝，局部算术开销有所转移；收益主要来自地形深度边缘 |
| 水下光束历史 | `global/water/shaft_history.glsl`、`lib/effect_history.glsl`：历史有效性查询返回已读的效果状态，复用其中的前帧时间 | 有效路径的状态读取由四次变为三次；原时间响应、四角距离拒绝、压缩域对比范围和历史权重保留 |
| 独立效果与植被 TAA 状态 | `lib/effect_history.glsl`、`lib/taa_state.glsl`：当前帧拒绝先于纹理读取；视口、效果和身份记录按拒绝顺序读取 | 启动、时间跳变或大距离移位无需读状态；视口／介质不匹配只读第一格，效果不匹配不读第三格。所有原拒绝条件继续保留，状态格式与版本不变 |
| TAA 场景解析 | `program/taa_resolve.fsh`：重投影范围判定先于历史状态查询 | 屏幕外候选无需读取状态；保留导数求值位置、反应遮罩、历史深度容差、颜色范围与混合权重 |
| 下界岩石反射 | `program/nether_reflection.fsh`：以法线惩罚计算历史有效性的上限，上限已不足以产生历史贡献时跳过颜色／深度载荷读取 | 深度惩罚只会进一步降低有效性；继续沿用原法线系数、最小当前帧权重和最终指数。每个可用历史足迹增加一次公共对数求值，减少拒绝角点的载荷读取及后续指数；收益与法线边界覆盖有关 |
| 下界体素彩光 | `program/nether_light.csh`、`shaders.properties`：两种火焰光源的纯时间闪烁移到共享 `astraNetherEmissionPulse` 表达式 | 保留两种闪烁的频率、幅度、颜色和光源身份；64³ 网格、同帧九阶段、六邻居传播及衰减不变。Iris 1.11.2 的 `ShadowCompositeRenderer` 已具备 compute 自定义 uniform 的绑定和推送路径 |
| 下界表面光照 | `global/dimension/nether.glsl`：零光级跳过非线性光照曲线，普通发光材质跳过传送门专用闪烁正弦 | 保留所有非零光级的原曲线以及传送门的原闪烁幅度和频率；没有提高发光强度 |
| 阴影的关闭选项组合 | `global/lighting/shadowmap.glsl`：主世界彩色阴影和焦散同时关闭时，直接组合已配对的透明深度权重 | 此时水与非水投射物的透射色均为白色，无需读投射物颜色；保留原深度比较和透明覆盖。默认开启效果时仍走原路径，下界／末地不采用此捷径 |
| 末地吸积盘转移图 | `global/dimension/end_kerr.glsl`：缺失射线格点在分支距离和坐标累加前退出 | 保留四个图集角点读取，包括零插值权重但仍参与径向足迹的有效角点；仅略去原本坐标权重及径向贡献都为零的无效格点运算 |

## 其余模块的审查结论

| 模块 | 当前结论 |
|---|---|
| 地形、实体、粒子与透明物 | 当前材质裁切、发光身份、雨湿分类和透明混合均有画面消费者；不采用省去粒子阴影或简化透明介质照明的方案 |
| 植被、表面光照与投影 | 时间风相位已有共享计算，风场距离衰减及视景／投影对应关系保留；花草投影、彩色阴影过滤与植被透光继续使用现有预算 |
| 焦散、光束生产与水下显示 | 现有波面缓存、短距离积分、九点光束重建、扩散及显示曲线保留；本轮只调整反射重复介质求值和历史数据读取 |
| 天空、日月、星空与环境缓存 | 当前 CPU 天体参数、星点重建、天空缓存和粗糙度 mip 查询继续使用；不改变刚完成的群星效果 |
| 云影与云历史 | 世界云影、屏幕云历史和反射天空继续独立；不删减当前帧密度查询，不使用稀疏跨帧更新改变运动表现 |
| 可选体积雾步进 | 保留原步数、积分模型和直射阴影查询；当前云影透射下限为 0.07，不增加无法在有效云影中触发的零透射分支 |
| 下界雾与反射空间重建 | 保留五类群系雾、颜色混合域、25 个空间足迹及逐角点资格／共面性判定；体素和反射的本轮修改见上表 |
| 末地天空与地表 | 保留天空原生分辨率、Kerr 图集、流动纹理、星点过滤、光子环、几何遮挡及地表光照；不增加亮度截断或减少吸积盘细节 |
| Bloom、FXAA、曝光与调色 | 现有启停条件、采样档位和颜色变换次序保留；不以减少默认 Bloom 或扩大 FXAA 边缘阈值作为优化手段 |
| 资源和维度调度 | 没有新增纹理、缓冲或渲染阶段；新增一个只由启用的下界体素链消费的 `vec2` 自定义 uniform。继续使用既有尺寸、格式及停用调度 |

## 结果边界

本轮保留既有主要画质预算和效果参数。运算顺序重组、CPU 与 GPU 三角函数以及有效性上限的对数比较可能产生微小浮点差异，不据此宣称输出逐位一致。

改动已经写入工作区源码；本轮没有新的游戏画面或帧率数据。能确定的是源码中的重复工作被裁减，具体 GPU 耗时受驱动优化、片元分支一致性和场景覆盖率影响，不能据读取数量推导固定帧率提升。
