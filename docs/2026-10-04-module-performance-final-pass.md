# 2026-10-04 各模块性能开销审查与修复

## 结论范围

以上为源码中的计算和读取裁减。分支收益与场景覆盖、GPU 驱动和编译器优化有关；例如 AO 固定偏移、反射公共表达式可能原本就被驱动折叠或合并，不能把源码运算数量直接折算为帧率。

四次水下视差运算的重排，以及 AO 常量求值与 GPU 运行时求值的差别，可能产生微小浮点变化。画质参数和主要采样预算未降低，本文不承诺像素逐位相同。

本轮修改保存在项目工作区；当前游戏画面与 GPU 耗时没有新增数据。
