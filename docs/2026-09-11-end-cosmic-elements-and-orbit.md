## 一、雨滴：读 ITT 源码的结论（我之前的做法是方向性错误）

### ITT 怎么做的

`Lib/Programs/Gbuffers/Weather_FS.glsl` 全文只有 20 行，核心三行：

```glsl
vec4 tex = texture(tex, texCoord);
if (tex.a < 0.1) discard;
gbufferOutput0 = vec4(0.0, 0.0, 0.0, tex.a);   // 纯黑 + 原版 alpha
```

**它根本不画雨丝**。做法是：

1. **形状完全交给原版纹理**（`assets/minecraft/textures/environment/rain.png`）
2. 只用一个 alpha 阈值把细碎部分剔掉
3. 输出**纯黑**——雨是"让背后变暗的水幕"，不是自发光的白丝

### 原版纹理实测（我解包量的）

| 指标 | 实测值 |
|---|---|
| 尺寸 | 64 × 256 |
| 不透明像素占比 | **2.5%**（极稀疏） |
| 竖向雨丝长度 | p10=1、p50=2、p90=9、**max=16** 像素 |

**结论**：原版纹理本身就是**又稀疏、又错落、长短差 16 倍**的。我上一轮用程序化栅格去"重画"雨丝，等于把一个专门做好的随机纹理替换成了规则点阵——这就是"太整齐"的根因，**不是参数问题**。

### 我提议的改法（照 ITT）

```glsl
// 用原版雨纹理的 alpha 作为形状；输出近黑的低饱和灰
float rainAlpha = texture(gtexture, texcoord).a * tint.a;
if (rainAlpha < 0.1) discard;
albedo = vec4(vec3(0.06, 0.07, 0.08) * rainAlpha, rainAlpha * 雨量强度);
```

要点：
- **删掉整套程序化雨丝**（栅格、抖动、长度分布全部不要）
- 颜色从 `vec3(0.62)` 灰改成**近黑**（雨水让背景变暗，而不是发亮）——这直接解决"扎眼"
- 稀疏度由原版纹理的 2.5% 覆盖率天然给出，不需要我们再控密度
- 保留"雨量驱动强度"和近距淡出

## 二、公转：先说清一个硬约束

### 现有数据链

```
引擎世界时间 → sunAngle → shadowLightPosition → (Iris) 渲染阴影贴图
                                    ↓
                        Astra uniform `lightVector`
                                    ↓
                    黑洞方向 = normalize(view_player(lightVector))
```

**关键**：影子贴图和黑洞方向**来自同一个 `shadowLightPosition`**。所以"黑洞公转 + 影子跟着转"这两件事，只要黑洞跟随 `lightVector`，就**自动同时成立**——这也是你之前那条"恒星方向必须与地形阴影一致"的实现方式。

`CelestialUniforms` 反编译确认：`isDay()` 为真用太阳方向，为假则 **`sunAngle - 0.5`（切到月亮）**。

### 由此得出的三条

| 方案 | 效果 | 代价 |
|---|---|---|
| **A. 跟随引擎光（现状）** | 公转与阴影**天然同步**，不需要额外工作 | 周期 = 世界日 ≈ **20 分钟/圈**，光影内**无法减慢**；且日/夜切换时方向**跳变 180°**（切到月亮） |
| **B. 光影自定慢速公转** | 可做到任意慢（如 40 分钟/圈），黑洞与"我们用来着色的光"一致 | **阴影贴图仍由引擎方向渲染** → 影子方向与天体不一致。违反你"阴影随之变化方向"的要求 |
| **C. 混合** | 黑洞自定慢速公转，同时放弃末地阴影跟随（把末地当作无方向阴影） | 末地会失去方向性投影，岩体明暗变平 |

### 我的建议

**先按 A 确认现状**，因为有两种可能：
- 若你世界里**时间在走**：黑洞其实一直在公转、影子也一直跟着——只是 20 分钟一圈、且每 10 分钟会在"日/月"之间跳一次方向。那我们要修的是**跳变**（让末地只用太阳方向，并让地形着色也用同一个方向，避免夜半跳转）。
- 若你世界里**时间被冻结**（例如服务器固定时间）：那它当然不动，而光影无法凭空造出时间——**只能走 B/C，并接受阴影不一致**。

> 如果你确实要"慢 + 阴影一致"，唯一的干净解法在光影之外：**把世界的日长调长**（游戏规则/数据包）。光影能做的只有跟随。

**请先告诉我：你测试的存档在末地时，时间是流动的还是冻结的？** 这决定走 A 还是 B。

## 三、末地"宇宙感"要素清单

按七组列出。★=已有、☆=部分、✗=缺。

### A. 尺度与星空层次（决定"深邃"）
| # | 要素 | 现状 |
|---|---|---|
| A1 | 星点数量与银河带分布（不是均匀撒点） | ★ ITT 星场已移植（含太阳轴对齐） |
| A2 | 星等幂律：少数亮星 + 大量暗星 | ★ 用 `remapSaturate` + coverage 实现 |
| A3 | 星色温分布（冷蓝↔暖橙，黑体色） | ★ `bh_Blackbody(4000~8000K)` |
| A4 | 远景星云/尘埃带（暗尘遮光 + 亮区发光） | ☆ 只有 15% 覆盖的亮星云，**没有暗尘带** |
| A5 | 无限远感（星空不随移动、极慢自转） | ★ 星场有 `frameTimeCounter*0.001` 自转 |
| A6 | **多层视差**（近星云动、远星不动） | ✗ 全部同速 |

### B. 主天体（决定"主体性"）
| # | 要素 | 现状 |
|---|---|---|
