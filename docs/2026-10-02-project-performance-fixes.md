# 项目源码审查与性能修复（2026-10-02）

本轮围绕当前 `Astra/shaders/` 的渲染调度、缓冲生产与消费、地形光照、水体、云历史、可选体积雾、下界反射、体素传播、末地天空和后处理展开源码审查。改动接续工作区现有实现。

## 实现边界

天光配对仍表示原来的 128 个等面积球面单元：下半球使用同一上半球辐射的 0.08 倍，Y 奇函数项的合并系数为 `1−0.08`，偶函数项为 `1+0.08`。改变求和次序可能产生浮点末位差异。该功能默认关闭，不能把这里的查询减半表述为默认整包耗时减半。

其余裁减依据零贡献或原有拒绝条件，不降低现有非零样本的质量预算。晨雾修正会改变晨昏山谷与高处的雾强度。下界反射复用半浮点法线可能在原法线拒绝阈值附近改变个别贡献者。

本轮结果来自源码审查，当前游戏画面、驱动加载表现与帧率收益尚未确认；以上次数仅表示对应代码路径的工作量。
