## 最终接口（实际声明）

```glsl
void astra_sh9_basis(vec3 direction, out float basis[9]);          // 内部共享基函数
void astra_sh9_clear(out vec3 coefficients[9]);
void astra_sh9_accumulate(inout vec3 coefficients[9], vec3 unitDirection, vec3 radiance,
                          float solidAngle);
vec3 astra_sh9_radiance(vec3 coefficients[9], vec3 unitDirection);  // 辐射亮度低阶重建（辅助）
vec3 astra_sh9_irradiance(vec3 coefficients[9], vec3 unitNormal);   // 余弦卷积辐照度
vec3 astra_sh9_diffuse_radiance(vec3 coefficients[9], vec3 unitNormal); // = irradiance / pi
```

与建议签名一致；额外提供 `astra_sh9_basis`（投影与求值共用的唯一约定来源）与
`astra_sh9_radiance`（重建辐射亮度场，便于接入期调试 / 混合，非物理输出项）。
`accumulate` 的 `solidAngle` 是外部提供的立体角权重（弧度 sr），模块不猜测样本数、不除以采样次数。

## 系数排列、轴方向与归一化

方向使用**玩家相对世界坐标**、期望已归一化；**+Y 为上方**（与 `worldNormal.y`、
`astra_sky_radiance(worldDir)` 的 `worldDir` 一致）。索引顺序为标准顺序，极轴映射到世界 +Y：

| 索引 | 基函数 | 常量 |
|---|---|---|
| 0 | `K0` | `K0 = 0.2820947918 = 1/(2√π)` |
| 1 | `K1 * y` | `K1 = 0.4886025119 = √(3/4π)` |
| 2 | `K1 * z` | |
| 3 | `K1 * x` | |
| 4 | `K2 * x*y` | `K2 = 1.0925484306 = √(15/4π)` |
| 5 | `K2 * y*z` | |
| 6 | `K20 * (3y²-1)` | `K20 = 0.3153915653 = √(5/16π)` |
| 7 | `K2 * x*z` | |
| 8 | `K22 * (x²-z²)` | `K22 = 0.5462742153 = √(15/16π)` |

基函数在单位球面上正交归一：∫ Y_i² dΩ = 1。投影 c_i = ∫ L(ω) Y_i(ω) dΩ，
求值 L(d) ≈ Σ c_i Y_i(d)，两者都经 `astra_sh9_basis()`，约定不会漂移。
注意：索引不附教科书 Y_l^m 上标——极轴从 +Z 移到 +Y 后 m 编号依赖旋转约定，
本模块不需要它；若将来要与外部 SH 库交换系数，按上表多项式列对号，不要按索引。

余弦核卷积因子（仅 `astra_sh9_irradiance` 使用）：`A0 = π`、`A1 = 2π/3`、`A2 = π/4`。
单位反照率朗伯出射量 = 辐照度 / π。

## 预期输入范围（供 H1 生产阶段）

- `unitDirection`：世界坐标单位向量（零向量安全跳过，不产生 NaN）。
- `radiance`：HDR 线性辐射亮度，单位与 `astra_sky_radiance()` 返回值一致（含暮光、闪电等叠加）。
- `solidAngle`：该样本代表的立体角（sr）。权重覆盖整球时总和应为 4π；模块不做任何 1/N 归一。
- `coefficients`：量纲为 radiance·sr，**允许负值**。全常量环境 L 时仅 c0 = 2√π·L ≈ 3.5449·L，
  其余为零；不是“九个方向样本”，不能逐项截为非负。

## 关键数学约定（已按推导核对）

1. 常量环境 L：任意单位法线 `astra_sh9_irradiance` = πL；`astra_sh9_diffuse_radiance` = L。
2. 零环境（`astra_sh9_clear` 后）：所有输出为 0。
3. 权重覆盖整球时总立体角 = 4π。
4. 数值核对（本机 awk，Fibonacci 球面均匀采样，无新增仓库工具/文件）：
   - 立体角总和 = 12.566371 = 4π；
   - 常量 L=(1,2,3)，法线 (0,1,0)/(1,0,0)/(0,-1,0)：E=(π,2π,3π)，diffuse=(1,2,3)，与解析一致；
   - 方向场 L(d)=1+d.y（解析 E(n)=π+(2π/3)·n.y）：n.y=-0.5/0/0.5/1 时 E=2.094395/3.141593/4.188790/5.235988，逐点吻合。

## 负值处理限制

系数与辐照度均**不逐项截断**。低阶重建在强梯度（如日月边缘）处可能给出轻微负值，按契约
只在 H1 最终物理输出处处理（若需），不得对单个系数取 max(.,0)——那会偏置其它方向的 $\text{重建}$。
