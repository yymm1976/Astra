# 第 3 步方案（原创）：末地环 —— 献给"围着末地岛公转"

**这是提案，不是实现。等你确认后我才动手。**
明确约束：不抄 ITT 的 `PlanetEnd2`（带环行星 + 大气 + 环上影带），要有自己的形态与机制。

---

## 一、先说清一件事：什么能做、什么做不到

你要"公转 + 阴影随之变化方向"。这里必须如实说明技术边界：

| | 能否做到 | 原因 |
|---|---|---|
| 天体**位置**缓慢公转 | ✅ | 纯天空着色器计算，完全自由 |
| 天体**自转**（盘内物质环流） | ✅ | 第 2 步已实现 |
| 公转**改变场景明暗**（大尺度、缓慢） | ✅ | 用一个"食"相位因子调制环境/雾，参考的 `planetShadow` 就是这个套路 |
| 公转**改变地形硬阴影的方向** | ❌ | 阴影贴图由 Iris 用 `shadowLightPosition` 渲染，光影无法改它的方向。**参考也没有这么做** |

所以我的方案把"阴影随之变化"落地为**两层可实现的替代**：
1. **环食**（大尺度明暗，周期约数分钟）—— 相当于"被环的影子扫过"，视觉上就是光在变；
2. **缘光方向随公转** —— 环上碎块的受光边朝向随公转改变。

如果你要的是"硬阴影方向跟着转"，那只能让该天体成为引擎光源（约 20 分钟一圈、无法调慢）。**请明确你要哪一种。**

## 二、核心方案：「末地环」(The End Halo)

> **2026-09-11 重要修正（用户提问 + 源码复核）**
>
> 你问"玩家在外岛时贴图会不会跟过去"。**会——如果按我最初写的"世界空间环、半径 180～420 格"来做。**
> 我去核了参考：`Lib/IndividualFounctions/EndSky.glsl` 全文**没有任何 `cameraPosition` 或世界坐标引用**，
> `PlanetEnd2(finalComposite, vec3(0.0), worldDir, worldSunVector)` 的 eye 实参就是 `vec3(0.0)`——
> 也就是说参考的星场、黑洞、行星**全部是纯方向（无限远）**，永远不会跟着玩家走。
>
> 所以本方案改为**天球环（celestial ring）**：环由"与一根缓慢进动的轴成固定夹角的那些方向"定义，
> **纯方向计算、不含任何世界位置**。这样：
> - 主岛、外岛、任何地方看到的环**完全一致**，不会"跟过去"；
> - 与星空无相对视差（和真实远天体一样）；
> - 实现更简单便宜：一次点积 + 若干噪声查表，比原方案还省。
>
> 下面的 2.2 已按此改写。

### 2.1 为什么选这个形态

末地本身的地理就是**中央岛 + 外圈岛屿环**。所以"环绕主岛的一圈天体"不是我硬塞的设定，而是**把末地既有的地理逻辑延伸到虚空中**——这是它和 ITT"一颗行星"最本质的区别：**圈层而非球体，环绕玩家所在的岛而非另一个天体**。

### 2.2 三个部件

**① 主环（The Halo）**

- 一条**天球碎屑带**：定义为"与一根缓慢进动的轴夹角落在 `θ₀ ± w` 内的方向集合"（θ₀≈70°、w≈9°），
  **纯方向、无限远、无世界坐标** —— 因此全末地一致、不会跟随玩家
- 两层结构：**尘埃片**（宽、暗、连续）+ **离散碎块**（窄、亮、稀疏，受光侧有缘光/rim）
- 缓慢公转：**轴的进动** = 整条带在天空中缓慢改变取向；带内碎块还有**沿带方向的差速环流**
  （沿带方向也做 `φ*(1-k·径向)` 缩放 + 噪声平移，与吸积盘同一套机制），因此形态会缓慢剪切重组
- 会**遮挡背后的星空**，这是"立体"的关键
- 受光：面向黑洞方向的一侧有缘光，背向侧近黑 —— 碎块有体积感而不是剪影贴纸

**预览图（离线渲染，用与方案相同的数学）**：

在线性尘埃带方案下渲染的第一版（`images/end-halo-preview.png`）**被判定为丑**，
原因经排查是两条设计错误，均已修正：

1. **黑色剪影在黑色天空上不可见**。天空本身就是近黑的，纯剪影只能露出被照亮的边缘，
   于是整条带read成"划痕/月牙"。天上的天体之所以看得见，是因为它是**被照亮的实体**。
   → 改为**受光表面**：浅穹顶法线点乘光照方向（光照方向在环坐标系内表示），带表面颗粒。
2. **用噪声密度做形态 = 一团污渍**。宽带上叠噪声，无论参数怎么调都读成"抹痕"。
   → 改为**离散、可辨识的形体**：少量、巨大的岛状剪影，各自有平顶与收窄的下缘。

修正版见 `images/end-halo-preview-v3.png`：三格分别是不同公转相位，
可见巨大的受光岛体缓慢飘过虚空，黑洞在旁。

**必须如实说明的限制**：这是**几何与构图关系的离线近似**。黑洞用解析替身（正式版是
50 步步进），没有最终材质、细节纹理、泛光与色调分级。Python 预览**无法代表最终观感**，
它的作用只是确认"形态/大小/疏密/遮挡关系"这一层。

**② 环食（The Eclipse）** ← 这就是"公转带来光影变化"的实现

- 主环平面相对"玩家→黑洞"视线是倾斜的，因此公转会周期性地让环**挡在黑洞前面**
- 那一刻：环的剪影横切光子环与吸积盘（视觉高潮），同时全场光照按食相位**轻微变暗**
- 周期：由环的公转周期决定，**默认 20 分钟一圈**（比参考的 15 分钟更慢，符合你"一定要慢"）
- 这是原创机制：参考的行星是用"行星影调制雾"，我们用的是"**环挡黑洞**"——遮挡物和受光物是同一个系统

**③ 次级碎片带（The Drift）**

- 一条更稀疏、**倾角不同、方向相反**的小碎屑带，半径更大（600～900 格）
- 提供第二层视差与"这是一个系统"的层次感，成本极低

### 2.3 技术实现与成本（对齐"极致优化"）

| 项 | 做法 | 成本 |
|---|---|---|
| 几何 | **纯方向**：一次 `dot(dir, axis)` 得到夹角 → 落在带内 → 方位角 + 径向噪声切块。**不做 raymarch、不做求交** | 每像素 1 次点积 + 2～3 次噪声查表（比原方案更省） |
| 遮挡 | 只在天空像素绘制（`depthtex == 1`），地形自动遮挡 | 零额外 pass |
| 星场遮挡 | 在星场之后、黑洞之前合成 | 零成本（本来就在同一函数里） |
| 环食 | 一个标量相位因子，乘在黑洞贡献与环境光上 | 零成本 |
| 缓冲 | **不需要任何新缓冲**、不需要 compute、不需要新 pass | — |
| 一致性 | 无世界坐标 → 主岛/外岛/任意位置完全一致 | 零成本 |
| 贴图 | 复用现有 `solaWaterNoise`（512×512）做团块噪声 | — |

对比参考：`PlanetEnd2` 每个天空像素要做球体求交 + 大气光学深度 + 5 阶 FBM 环结构 + 3 个圆盘函数；
我的方案是平面求交 + 少量噪声，**天空像素的成本约为参考的 1/4～1/3**。

### 2.4 选项（建议暴露，都可关）

| 选项 | 说明 | 默认 |
|---|---|---|
| `END_HALO` | 主环开关 | 开 |
| `END_HALO_PERIOD` | 公转周期（分钟）：`[10 15 20 30 45 60]` | **20** |
| `END_HALO_DENSITY` | 碎块密度 | 中 |
| `END_HALO_ECLIPSE` | 是否启用环食及其变暗 | 开 |

## 三、备选方案（如果你不喜欢主环）

**备选 A：「碎星带」** —— 一条被拉长的潮汐碎片流（像彗尾），沿轨道缓缓流过视野。
更含蓄、成本更低；但形态不如环有"系统感"，且难以承载"环食"这个高潮。

**备选 B：「双星」** —— 一颗暗蓝色伴星在黑洞对面公转，并给地形加一道**无阴影的第二方向光**。
优点：**能让方块亮面随公转摆动**（这是"光影随公转"最直白的实现）。
缺点：两个天体 + 两套光照容易显得杂乱，且与"清爽不抢戏"的定位有张力。

**我的建议：主方案「末地环」。** 它同时满足公转、慢、立体、遮挡星空、带来光影变化，
而且是"从末地自身地理长出来的"设定，不是外来物。
