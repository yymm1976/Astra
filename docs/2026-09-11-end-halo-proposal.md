# 第 3 步方案（原创）：末地环 —— 献给"围着末地岛公转"

**这是提案，不是实现。等你确认后我才动手。**
明确约束：不抄 ITT 的 `PlanetEnd2`（带环行星 + 大气 + 环上影带），要有自己的形态与机制。

---

## 一、先说清一件事：什么能做、什么做不到

你要"公转 + 阴影随之变化方向"。这里必须如实说明技术边界：

| | 能否做到 | 原因 |
|---|---|---|
| 天体**位置**缓慢公转 | ✅ | 纯天空着色器计算，完全自由 |
| 天体**自转**（盘内物质环流） | ✅ | 第 2 步已实现 |
| 公转**改变场景明暗**（大尺度、缓慢） | ✅ | 用一个"食"相位因子调制环境/雾，参考的 `planetShadow` 就是这个套路 |
| 公转**改变地形硬阴影的方向** | ❌ | 阴影贴图由 Iris 用 `shadowLightPosition` 渲染，光影无法改它的方向。**参考也没有这么做** |

所以我的方案把"阴影随之变化"落地为**两层可实现的替代**：
1. **环食**（大尺度明暗，周期约数分钟）—— 相当于"被环的影子扫过"，视觉上就是光在变；
2. **缘光方向随公转** —— 环上碎块的受光边朝向随公转改变。

如果你要的是"硬阴影方向跟着转"，那只能让该天体成为引擎光源（约 20 分钟一圈、无法调慢）。**请明确你要哪一种。**

---

## 二、核心方案：「末地环」(The End Halo)

### 2.1 为什么选这个形态

末地本身的地理就是**中央岛 + 外圈岛屿环**。所以"环绕主岛的一圈天体"不是我硬塞的设定，而是**把末地既有的地理逻辑延伸到虚空中**——这是它和 ITT"一颗行星"最本质的区别：**圈层而非球体，环绕玩家所在的岛而非另一个天体**。

### 2.2 三个部件

**① 主环（The Halo）**

- 一圈**倾斜的碎屑环**，围绕末地主岛（世界 XZ 原点附近），半径约 **180～420 格**，竖向厚度薄
- 由大量**暗色碎块**构成（末地石/黑曜石色，低反照率、锐利高光），不是连续圆环——用噪声在 (角度, 半径) 上切出疏密团块，留出大量空隙
- 缓慢整体公转；环内不同半径的角速度**略有差异**（差速），使团块缓慢剪切、形态会缓慢重组
- 因为它在**真实世界半径**上，玩家移动时有**真实视差**；它还会**遮挡背后的星空**，这是"立体"的关键
- 受光：面向黑洞方向的一侧有**缘光**（rim），背向侧近黑 —— 让碎块有体积感而不是剪影贴纸

**② 环食（The Eclipse）** ← 这就是"公转带来光影变化"的实现

- 主环平面相对"玩家→黑洞"视线是倾斜的，因此公转会周期性地让环**挡在黑洞前面**
- 那一刻：环的剪影横切光子环与吸积盘（视觉高潮），同时全场光照按食相位**轻微变暗**
- 周期：由环的公转周期决定，**默认 20 分钟一圈**（比参考的 15 分钟更慢，符合你"一定要慢"）
- 这是原创机制：参考的行星是用"行星影调制雾"，我们用的是"**环挡黑洞**"——遮挡物和受光物是同一个系统

**③ 次级碎片带（The Drift）**

- 一条更稀疏、**倾角不同、方向相反**的小碎屑带，半径更大（600～900 格）
- 提供第二层视差与"这是一个系统"的层次感，成本极低

### 2.3 技术实现与成本（对齐"极致优化"）

| 项 | 做法 | 成本 |
|---|---|---|
| 几何 | **解析求交**：视线与环平面求交 → 半径落在环带内 → 噪声切块。**不做 raymarch** | 每像素 1～3 次平面求交 + 数次噪声查表 |
| 遮挡 | 只在天空像素绘制（`depthtex == 1`），地形自动遮挡 | 零额外 pass |
| 星场遮挡 | 在星场之后、黑洞之前合成 | 零成本（本来就在同一函数里） |
| 环食 | 一个标量相位因子，乘在黑洞贡献与环境光上 | 零成本 |
| 缓冲 | **不需要任何新缓冲**、不需要 compute、不需要新 pass | — |
| 贴图 | 复用现有 `solaWaterNoise`（512×512）做团块噪声 | — |

对比参考：`PlanetEnd2` 每个天空像素要做球体求交 + 大气光学深度 + 5 阶 FBM 环结构 + 3 个圆盘函数；
我的方案是平面求交 + 少量噪声，**天空像素的成本约为参考的 1/4～1/3**。

### 2.4 选项（建议暴露，都可关）

| 选项 | 说明 | 默认 |
|---|---|---|
| `END_HALO` | 主环开关 | 开 |
| `END_HALO_PERIOD` | 公转周期（分钟）：`[10 15 20 30 45 60]` | **20** |
| `END_HALO_DENSITY` | 碎块密度 | 中 |
| `END_HALO_ECLIPSE` | 是否启用环食及其变暗 | 开 |

## 三、备选方案（如果你不喜欢主环）

**备选 A：「碎星带」** —— 一条被拉长的潮汐碎片流（像彗尾），沿轨道缓缓流过视野。
更含蓄、成本更低；但形态不如环有"系统感"，且难以承载"环食"这个高潮。

**备选 B：「双星」** —— 一颗暗蓝色伴星在黑洞对面公转，并给地形加一道**无阴影的第二方向光**。
优点：**能让方块亮面随公转摆动**（这是"光影随公转"最直白的实现）。
缺点：两个天体 + 两套光照容易显得杂乱，且与"清爽不抢戏"的定位有张力。

**我的建议：主方案「末地环」。** 它同时满足公转、慢、立体、遮挡星空、带来光影变化，
而且是"从末地自身地理长出来的"设定，不是外来物。
