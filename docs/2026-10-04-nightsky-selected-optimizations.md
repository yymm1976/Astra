# 2026-10-04：SUMMARY-nightsky 必要优化

依据 `shader_research/SUMMARY-nightsky.md`，对照当前主世界星空与本地 Photon、Bliss、Complementary、Aurora Fantasy 源码，选取星空运动、星点连续性和低成本群星层次。报告作为调研材料使用，其建议顺序不等同于本轮开发范围。

## 已实施

| 改动 | 当前行为与目的 |
|---|---|
| 天体坐标 | 从既有归一化太阳方向和 `sunPathRotation` 得到天轴与切向；星点位置随实际日月运行，不再独立地水平漂移。太阳方向不依赖昼夜投影光源交接，因此星空不会随投影光源切换而翻转。世界时钟停止时，星点位置也停止转动 |
| 平滑星点 | 固定整数格点提供星点身份，四个相邻格点按三次平滑权重重建，替代整格亮度硬切换。格点边界的颜色与一阶导数连续；这不等于所有分辨率与视野下的严格像素积分 |
| 全天球投影 | 保留球面投影，采用两片在天轴赤道附近平滑交叠的区域。每片只在安全范围求值，避免将旧的上半球公式直接旋转后产生零分母；两极也有有效坐标。一般区域查询四个格点，交叠带查询八个 |
| 冷暖色与闪烁 | 星点有轻微暖白、白色及冷白变化；采用有限色板近似色温，不引入每星黑体拟合。每星相位与幅度固定，时间相位在 CPU 计算；闪烁系数限制在约 `0.9505–1.0495`，不会整片同步明灭 |
| 亮星层次 | 较亮星点从同一格点结果中产生；只对亮度排名最高的少量星点增加最多 35% 强度，没有增加第二套大范围星场或光芒采样 |
| 星量选项 | 天空与云菜单增加「星空密度」：关闭、稀疏、标准、密集、繁星；默认标准。与既有星星总开关共同生效，关闭密度时入口直接返回零 |
| 开销裁减 | 格点随机数采用整数乘法与位运算；日夜／雨量可见性移至 CPU，复用已有太阳归一化结果。完全不可见、地平线以下及查询后无星点的区域提前返回；无星点区域省去日月遮蔽的高次幂运算 |
| TAA 衔接 | 默认平面云及关闭云的天空分支复用同一次星点结果，将有星光贡献的像素标为完全反应区域，避免随天体移动的星点沿用旧位置形成拖尾；不扩大地形或无星光晴空的反应范围 |

默认格点出现概率为 `0.0058`，接近旧三层均匀随机乘积大于 `0.7` 时的理论概率；亮度采用四次方分布，保持大量微弱星点与少量亮点。新的格点种子和天球方向会改变具体星点分布，不能把统计接近理解为原画面的逐星位置或亮度一致。

## 消费端与保留范围

- 主世界星空继续使用同一 `astra_star_field` 实现；默认云模式下，`deferred.fsh` 在天空深度分支按原 `astra_overworld_sky` 的顺序分别取得天空与星光，以复用星光结果设置 TAA 反应值，再沿用云层透射遮挡。原版云模式的可见天空仍由既有 `sky.fsh` 路径合成。
- 地平线衰减、日月邻域星光抑制、晨昏淡入淡出和天气响应保留。夜空底色、白天大气、地面照明及水体参数没有改动。
- 原版云模式已将整个天空设为完全反应区域；默认平面云模式原来只在云有贡献时拒绝历史，本轮补齐有星光贡献的晴空像素。复用既有 TAA 遮罩，没有单独新增星点历史。
- 天空反射缓存继续采用现有的平滑天空与云颜色；星点没有塞进低分辨率缓存，也没有扩大各反射射线的求值负担。
- 末地星场是独立的球面星表与解析滤波系统，本轮主世界实现没有替换它。

## 报告纠正与未采用项

1. 主世界虽未声明原始 `worldTime/worldDay` GLSL uniform，但 `shaders.properties` 已使用世界时间，`sunPathRotation` 也是现有选项，且已有太阳世界方向。当前天体锚定直接复用这些信息，无需先新增四个原始 uniform。
2. 旧星场已经有 `min(1, 3 * VdotU)` 地平线衰减；报告所说「完全没有地平消光」不准确。物理透射 LUT 属于另一个大气方案，本轮没有改造天空体系。
3. 当前没有主世界极光或星云，云文件中的未移植注释不能单独证明云颜色存在运行错误；仅为了清掉注释而添加染云能量会改变夜景。
4. `sky_minishita.glsl` 的亮度常数是当前天空方案的调色选择。臭氧、假多次散射与全天亮度重配会影响白天和晨昏，不纳入星空局部调整。
5. 银河贴图、程序星云、体积极光、流星、星座连线与行星均是新增视觉功能。报告中的「几行级」描述不能代表它们接入 Astra 后的完整成本。本轮没有引入新贴图、新附件、额外星空阶段或体积积分。
6. 借鉴四邻域连续重建及逐星相位的思路，具体整数格点、双区域投影接线、色板与 CPU 表达式由 Astra 编写；原 Complementary 球面投影与可见性公式来源保留，出处同步至 `Astra/THIRD-PARTY.md`。
