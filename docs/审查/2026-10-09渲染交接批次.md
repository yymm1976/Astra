## 二、改动详细分析

### 2.1 水下光束（Light Shafts）改动

**文件**: `Astra/shaders/global/water/light_shafts.glsl`

#### 改动要点

1. **移除细焦散峰值放大和随机积分偏移**
   - **代码证据** (L58-82):
     - 新增 `water_shaft_source()` 函数，采用宽区域光源
     - 使用 0.075 缩放的世界空间网格 + 五次插值 (quintic smoothstep)
     - 移除了细粒度焦散立方放大 (注释 L65-67 提及 "cubing peaks made flashes")
   
   ```glsl
   // L68-82: 稀疏、缓慢变化的宽区域光源
   float water_shaft_source(vec2 entryXZ, float daylight) {
       float time = frameTimeCounter * (WATER_WAVE_SPEED * 0.01);
       vec2 at = entryXZ * 0.075 + time * vec2(0.025, 0.018);
       // ... quintic fade 连续插值
       float source = smoothstep(mix(0.69,0.57,daylight),
                                 mix(0.88,0.78,daylight),field);
   ```

2. **晴天、晨昏和夜间减弱机制**
   - **代码证据** (L88-95):
     ```glsl
     float daylight = astraSunSource * smoothstep(0.07,0.35,worldSunVector.y);
     visibility *= mix(0.11,0.45,daylight) * mix(0.55,1.0,astraSunSource);
     ```
   - 晨昏（worldSunVector.y < 0.35）时 daylight 降低 → source threshold 上升（L79）
   - 夜间（astraSunSource → 0）visibility 降至 0.11–0.55 的混合值
   - **符合性**: 与交接描述"晴天、晨昏和夜间均减弱"一致

3. **积分步数优先预算**
   - **代码证据** (L21-25):
     ```glsl
     #if !defined ASTRA_OVERWORLD_OPTIMIZED || UNDERWATER_SHAFT_SAMPLES < 7
         #define ASTRA_SHAFT_SAMPLES UNDERWATER_SHAFT_SAMPLES
     #else
         #define ASTRA_SHAFT_SAMPLES 7
     #endif
     ```
   - 注释明确说明："Balanced water retains all seven selected steps"
   - **性能影响**: 从 5 步恢复到 7 步会增加 40% 采样成本
   - **建议**: 需要实机对比 BALANCED 档位的帧率变化

4. **无随机积分偏移**
   - **代码证据** (L122-123):
     ```glsl
     // Deterministic midpoint quadrature of a broad source: no per-pixel or
     // per-frame random phase. Motion comes from the water field itself.
     ```
   - 确认使用确定性中点求积，无 Bayer 或帧号抖动
   - **稳定性**: 有利于避免噪点，但需验证时间连续性

#### 决议符合性检查

- ✅ SC-33 (design.md L117): "水下光束复用 composite 与 colortex1"
- ✅ SC-34-F1 (design.md L504): "界面与 composite 共用 astra_water_sun_source"
- ✅ 编码契约: RGB=sqrt(scatter/4), A=distance/96 (L170)

## 四、风险评估

### 4.1 性能风险 ⚠️

**风险**: 水下光束从 5 步恢复到 7 步可能影响 BALANCED 档位帧率

- **受影响档位**: BALANCED (目标 ≥90 FPS @ RTX 4050)
- **建议**: 
  1. 在典型水下场景（珊瑚礁、海底神殿）实测帧率
  2. 如果低于 90 FPS，考虑将 7 步仅用于 ULTRA 档
  3. 检查 `ASTRA_SHAFT_SAMPLES` 宏在三个档位的实际值

### 4.2 视觉验证需求 ⚠️

**需要游戏内截图确认的效果**:

1. **水下光束强度**: 晴天/晨昏/夜间/雨天的对比
2. **光束稀疏度**: 新的宽区域光源是否消除了颗粒感
3. **水面折射**: 身体颜色与深度接入是否正确（玩家手臂、实体等）
4. **日月反光**: 椭圆形状是否符合"纵长尖椭圆"描述
5. **云边缘**: 晨昏时薄云的过渡是否平滑

### 4.3 技术债务 ⚠️

**未解决的遗留问题**:

1. **格式声明悬而未决**: design.md SC-27 修订版提到"允许格式 const"，但代码中仍全部注释
2. **Voxy 适配**: SC-17 提到"C5 继续 Voxy 适配"，当前状态未知
3. **AO 模块**: diffstat 显示新增 `lib/ao_resolve.glsl`，但交接文档未提及
