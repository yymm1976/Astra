### A01 · P2 · 薄水层的自动曝光仍读取旧的场景附件

定位：[Astra/shaders/program/exposure.fsh:27](C:/Users/杨铭/Desktop/MC模组开发/Astra光影开发/Astra/shaders/program/exposure.fsh:27)。

**触发：** 主世界，AUTO_EXPOSURE开启，Bloom开启且强度大于0，DEBUG_VERTEX_AO为0，isEyeInWater==1且water_is_thin_sheet()。

**影响：** 薄水层下曝光适配透明绘制与水路合成之前的背景，显示却使用合成后的图；水帘、晚绘制实体和透明物变化不能正确参与亮度测量，且Bloom开关改变计量来源。

**依据：** exposure.fsh:29传colortex4；water_composite.fsh:17写9；display.fsh:122读取9。exposure.glsl:122仅普通介质冻结历史，薄水层继续astra_ae_meter(scene):127。deferred.fsh的4保存透明层之前的source。

**处理建议：** Bloom路径相机在水中时使用已合成的附件9；普通水体保持冻结曝光，薄水层继续适配。

### A02 · P2 · 失明雾的固定85%覆盖让淡出硬跳

定位：[Astra/shaders/global/atmosphere/fog.glsl:127](C:/Users/杨铭/Desktop/MC模组开发/Astra光影开发/Astra/shaders/global/atmosphere/fog.glsl:127)，以及 [nether.glsl:61](C:/Users/杨铭/Desktop/MC模组开发/Astra光影开发/Astra/shaders/global/dimension/nether.glsl:61)。

**触发：** 主世界或下界，blindness从正值淡出到0，普通空气或薄水层的几何/天空介质路径。

**影响：** 近处表面和主世界天空在失明即将结束时仍保持至少85%的黑色混合，退出分支时突然恢复普通雾；最终显示还受色调映射影响，不把该比例当作屏幕亮度比例。普通水体与末地不计入此同类分支。

**依据：** fog.glsl:127-129 和 nether.glsl:61-63 在blindness>.0001时采用 max(.85,1-exp(-distance^2*blindness^2*.25))，强度趋零opacity仍>=.85；退出分支立刻回普通雾。[Iris 状态 uniform 说明](https://shaders.properties/current/reference/uniforms/status/#blindness)将0到1的中间值用于效果过渡。

**处理建议：** 让近景覆盖下限随blindness一起趋零，同时保留满强度时的距离遮蔽；主世界与下界一致修正。

## 主要疑点裁决

| 候选判断 | 裁决与证据 |
|---|---|
| 薄水层曝光来源与显示不一致 | 采用，见 A01；普通水体的曝光冻结属于保留行为 |
| 冰的折射接受分支少了 water 条件 | 不采用；非水路径已提前返回，声称不同的两条分支对冰不可达 |
| 水下界面折射重复施加整段水雾 | 不采用；界面到背景与相机到界面是不同光程，普通水体相机段由最终合成负责 |
| 把水吸收选项用于光束核宽必然错误 | 不采用；当前消光系数确实包含该吸收参数，没有证明现有有界近似造成错误 |
| 水下缓存会在多个后处理阶段重复生成 mip | 不采用；mip 声明受 ASTRA_SHAFT_MARCH_PASS 限制；独立的薄水层多余生产见 A03 |
| 下界自定义图像没有逐帧清除 | 不采用；声明的清除布尔值为 true，本机 Iris 读取该值并执行清除 |
| 下界合成直接读写同一物理颜色图像 | 不采用；相关 composite 使用主/备用附件与默认翻转，不能把同一 colortex 名称等同于同一物理图像 |
| 下界关闭体素光后仍执行未绑定图像的阶段 | 不采用；相关九个阶段与图像声明使用一致的开关条件 |
| 计算阶段之间没有可见性处理 | 不采用；本机 Iris ComputeProgram.dispatch 的普通路径在 dispatch 前调用 memoryBarrier，不能仅凭 GLSL 缺少跨阶段声明断言失效 |
| at_midBlock / 64 的格心偏移错误 | 不采用；当前写法符合官方位置偏移说明 |
| 末地流场图集高层级越界或边界未环绕 | 不采用；实际图集为 514×1043，生成器含边缘扩展，各层位置与采样布局相符 |
| 缓存反射一定读取不存在的 mip | 不采用；相关非粗糙路径读取 LOD 0，粗糙缓存另有 mip 声明 |
| 显式 1.0×1.0 尺寸使附件28不能由几何入口写入 | 不采用；不能把文档的概括直接当作本机行为，本机 Iris 附件创建路径没有该推断中的声明存在性过滤 |
| 截图分析缺输入时没有提示具体文件 | 不采用；该脚本是指定截图的一次性分析，FileNotFoundError 本身包含缺失路径，不能称其隐藏了具体文件 |
| 独立末地预览固定部分参数必然是渲染缺陷 | 不作为现行渲染缺陷；预览有明确独立场景及固定参数，不覆盖全部游戏配置；过期行号属于说明维护 |
| 同步工具未删除目标目录额外文件必然导致错误 | 不作为当前缺陷；工具明确保留并报告额外文件，没有证据证明它们已造成当前加载错误 |
| 临时源码替换未检查次数必然使现有工具结果失真 | 不作为当前缺陷；所指替换标记当前存在，未来文本变化风险不冒充当前已发生的问题 |
