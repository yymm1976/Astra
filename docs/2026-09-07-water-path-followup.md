## 按实际执行顺序追踪

| 路段 / pass | 输入与输出 | 确定的问题与本轮处置 |
|---|---|---|
| 光源 → opaque `lit` | albedo ×（环境光 + 方块光 + 直射光），写 colortex0 | 水下环境光混入了额外日光；焦散乘整个场景。现在环境项不再含太阳，单独输出 `directRadiance`，焦散只调制此项。水下接收面的方向项使用折射入水光方向；入口 Fresnel 与入射水程透射各作用一次。 |
| `deferred` | opaque colortex0 → 未施加视线介质的 colortex4；显示场景写回 colortex0 | 保留现有副本顺序；采样源不含相机水程，防止水面再传播一次已雾化颜色。水下相机段的环境散射改取眼部体积的天光可达性，不随远端方块衰减后的 lightmap 变黑。 |
| `gbuffers_water` 界面 | 同一个波法线 → 反射方向、折射方向、Fresnel | 旧代码水下丢弃 SSR 命中，且拒绝折射天空深度；现在消费水下命中，空气侧无几何时按折射方向重建天空。Fresnel 使用水/空气 IOR 和完整介电式，保留全反射，不乘 skylight。只给环境天空回退施加天光可达性。 |
| SSR 命中 | depthtex1 → 命中 UV / depth / confidence | 旧的“朝相机返回即拒绝”会漏掉真实可见反射。20 次粗步进、4 次细分之后的残差也会造成命中空洞；现在用同一物体上的局部深度平面求交，再确认几何，消除用细分残差判断厚度的错误。 |
| 波面与反射过滤 | 世界波场 → normal / roughness → 场景足迹 | 固定视差循环次数，面类别选择移到导数之后；限制掠射时会使反射越过几何界面的法线坡度。反射过滤的每个颜色/深度样本都受同一表面平面约束，不在粗糙过滤时跨物体取亮色。保留既有波长、波高设置与消光系数。 |
| 折射 → 水体另一段 | 每个原始颜色样本 + 自己的深度 → 该段传播结果 | 删除“最远深度 + 双线性 RGB”的组合和按亮差猜边界。折射方向只产生一次，投影到深度平面迭代；逐点拒绝位于界面错误一侧的几何，分别传播再组合。失败时使用完整原位置光路；天空失败使用对应折射天空。 |
| `composite` → `final` | 眼睛至 depthtex0 最近表面的太阳散射 → colortex1 → 加入场景 | 与界面另一段共用 `astra_water_sun_source`、sigma、归一化 HG 相函数。太阳源含阴影可见度、入水损失和入射水程衰减；相机透射在积分权重内。移除独立亮晕、多倍增益和另造的聚光图案；16/24/32 段按当前可见水程分配。 |
| 半尺寸重建 | colortex1 四邻域 → final | 读取每个生产位置实际的完整尺寸深度，不用量化距离加 8% 宽容差决定边界。没有几何相近的邻域时不向前景贡献散射。 |
| `composite1` → `final` | bloom 提取 → mip 合成 → tonemap / sRGB / grading | 旧 bloom 虽称白色以下不发光，软阈值却从 0.5 开始。已使软阈值从既定 1.0 开始，不降低沙地原始亮度。其余显示链与已有方块光颜色保留。 |

散射账本：环境项在每段按 `L*T + ambient*sigma_s/sigma_t*(1-T)` 计算；太阳项通过同一空间光源场积分。地形上的入射水程属于光源到地形，反射/透射段属于地形到界面，相机段属于界面或可见地形到眼睛，这些是不同物理路径。水下界面最后施加相机段环境介质，太阳相机段由 composite/final 添加；界面反射命中的额外水程另行传播，不能省略。

## 白圈定位结论

代码层面最早的潜在放大在 opaque `lit` 的整色焦散乘法；明确的几何采样错配在 `gbuffers_water`；明确的普通沙色外溢在 `composite1` 的软阈值。均已分别修正。默认水上画面的水下光束分支不会执行，因此不能把该截图的白圈归罪于水下 colortex1 上采样。Astra 没有 TAA，本次也没有增加 TAA。

这些是代码与受控渲染能够证实的缺陷，尚未捕获用户当前游戏场景每个 pass 的附件，不能声称已经在真实场景确定三者的贡献比例，更不能把“游戏沙子 halo 完全消失”写成已通过。

## 约束与待实测项目

没有新增 pass、缓冲或 varying。SSR 在原 20+4 追踪后增加局部平面及命中位置读取；界面太阳源用 4 段积分，过滤按采样路径先传输后组合；这些开销需用新游戏材料判断，未声称帧率不变。
