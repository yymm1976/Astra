# Astra

Astra 是开发中的 Iris 专用 Minecraft Java 版光影包，采用前向地形光照，提供独立的主世界、下界和末地效果。当前代码不使用 TAA 或跨帧画面累积。

## 安装与设置

将 `Astra/` 文件夹放入实例的 `shaderpacks/`，在 Iris 中选择 Astra。设置页提供中文与英文说明。

| 预设 | 主要取舍 |
|---|---|
| PERFORMANCE（流畅） | 1024 阴影、192 格影距；关闭 SSR、折射、Bloom、平面云及下界体素光 |
| NO_SHADOWS（无实时阴影） | 以流畅档为基础，进一步关闭阴影阶段及水下光束 |
| BALANCED（均衡，默认） | 2048 阴影、256 格影距；开启平面云、SSR、折射、Bloom 和下界体素光；空气体积光关闭 |
| ULTRA（极致） | 4096 阴影、256 格影距；更宽阴影核、物理天空和空气体积光 |

三档画质阶梯外另有 NO_SHADOWS 预设。四档均显式覆盖所有设置选项；切换预设会重置 AO 显示模式和岩石泛光强度。具体值以 `shaders/shaders.properties` 的 `profile.*` 为准，选项范围与出厂值位于 `shaders/lib/settings.glsl`。

## 当前功能

- 水：动态法线、屏幕空间反射与折射、按水中距离计算的吸收、解析焦散及水下光束。
- 大气：渐变与物理天空、平面云、雾、空气透视、生物群系染色。
- 光照：彩色阴影、植被透光、手持光、闪电、植被摇曳；软件与硬件阴影比较模式可选。
- 下界：独立光照与雾；可选体素彩色光在同一帧执行九个 compute 阶段。
- 末地：Kerr 黑洞天空、独立环境光与按方块身份控制的末地石泛光。
- 后处理：可选 Bloom、色调映射和颜色分级；自动曝光默认关闭。

## 实现状态与边界

- 地形光照在 gbuffers 阶段计算；后续效果仍使用深度、材质及场景颜色缓冲，并非没有中间缓冲。
- 水面与 SSR 模块已接入渲染链。不同维度使用根目录、`world-1/` 和 `world1/` 薄入口，具体实现在共享 `program/`、`global/` 与 `lib/`。
- Voxy 目前只有适配骨架；打开 `VOXY_SUPPORT` 不会启用可用的远景渲染。自定义维度沿用根层主世界链。
- 当前开发实例为 MC 26.2 / Iris 1.11.2。驱动可编译性与游戏加载、版本兼容、实际画面是不同结论；不据此宣称所有 1.21.x / 26.x 版本均可用。
- `../qa/screenshots/` 保存历史游戏画面，不能代表当前源码的效果。离线完整出图能力仅覆盖末地天空；主世界、下界和水下观感仍需游戏画面支持。
- 本文不承诺固定帧率，也不把历史工具输出当作当前状态。
