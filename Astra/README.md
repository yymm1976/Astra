# Astra

Minecraft Java 版 Iris 光影包，具有主世界、下界和末地独立效果。本文说明当前使用方式；开发待办、技术债与规划见 [当前工作](../docs/当前工作.md)，历史实施和审查资料从 [文档索引](../docs/README.md) 按需查找。

## 安装与设置

将 `Astra/` 文件夹放入实例的 `shaderpacks/`，在 Iris 中选择 Astra。设置页提供中文与英文说明。当前开发实例为 MC 26.2 / Iris 1.11.2；不据此宣称所有 Minecraft / Iris 版本均可用。

默认“均衡”档优先帧率：1024 阴影图、96 格覆盖、32 格实体投影、单组四角过滤；四层水面法线，开启折射与基础水雾，关闭屏幕物体倒影、Bloom、水下独立光束和下界体素彩光。天空反光、平面云、云历史平滑与 FXAA 保留。阴影边缘会更硬，水面细涟漪更少，不再显示物体倒影、高亮扩散与独立水下束光。选择“画质均衡”可恢复此前默认效果。

「性能与高级 → 主世界性能预算」默认为“进一步收紧”：阴影上限1024/112格，水上水平面32～64格渐退；默认原选项另将覆盖设为96格。“优先”上限1536/112格，水面48～96格渐退；“关闭”使用原质量选项。预算保留更低设置与关闭效果，不改变输出分辨率。精确参数由 `shaders/lib/settings.glsl` 和 `shaders/shaders.properties` 维护。Iris 已保存的单项设置会覆盖新默认，已有安装可选择“均衡”应用这套配置。

「颜色与风格 → 主世界配色」默认“清新自然”：参照 Steadfast 的清新方向，日光接近中性、环境光轻偏青绿、晴天天空略偏青蓝，晨昏保留暖色，饱和度轻微增强且对比度中性；也可选择“沿用原配色”。既有手动颜色方案与分层调色继续生效；切换画质档保留配色。配色不增加独立全屏阶段，也不启用自动曝光。

| 预设 | 原选项的主要行为；主世界开启预算时另受预算上限约束 |
|---|---|
| PERFORMANCE（流畅） | 512/80格阴影、四层水波；关闭实体投影、SSR、折射、Bloom、水下光束、平面云、抗锯齿和下界体素彩光 |
| NO_SHADOWS（无实时阴影） | 在流畅档基础上关闭实时阴影，保留静态明暗近似 |
| BALANCED（均衡，默认） | 1024/96格阴影、四层水波；恢复近处实体投影、平面云、折射、焦散、FXAA与植被运动 |
| QUALITY（画质均衡） | 恢复SSR、Bloom、水下光束、下界体素彩光、六层水波与中档缓存；主世界阴影受优先预算限制为1536/112格 |
| ULTRA（极致） | 解除主世界预算，4096/256格阴影、高档云与水体选项、物理天空和空气光束，开销明显较高 |

五档通过继承共用完整设置，颜色相关选项独立。各档关闭方向性天光、屏幕空间 AO 和步进体积雾；空气光束仅极致档开启。抗锯齿为关闭 / FXAA / TAA 三选一，TAA 需手动选择；预设切换会重置画质选项以及 AO 显示和岩石泛光强度。

低档“天空与云质量”把天空／末地倒影缓存核心设为128×64、云影缓存设为128×128；中高档分别为256×128、256×256。较低尺寸减少缓存生产和存储，倒影薄云与云影边缘更粗。平面云历史仍独立于TAA，末地屏幕天空保持原生尺寸。

当前完整三维度效果需要支持包内计算着色器和自定义图像的 Iris 环境。下界体素彩光需要自定义图像，末地星表也使用计算着色器；尚无缺少这些能力时的完整替代实现。具体版本能否正常加载与显示，不能只根据功能声明推断。

## 当前功能

- 水：动态法线、屏幕空间反射与折射、按水中距离计算的吸收、解析焦散及水下光束。
- 大气：渐变与物理天空、可配置分辨率的平面云与日月遮挡、全天候天空与云反射、独立世界空间云影缓存、雾、空气透视、生物群系染色，以及可选的步进体积雾（雾页开关，默认关闭）。平面云的独立时域历史可通过「云历史平滑」开关控制，以透射权重一阶矩为代表位置、真实前帧参数重投影，独立于 TAA。空气透视的恒定水平太阳方向每帧预计算；关闭表面云影、没有体积雾消费且雨量低于0.01时，云影缓存顶点阶段会裁掉整屏片元，雨天照明与体积消费仍保留。
- 雨湿地面：木材、土壤与石材采用不同暗化和轻微光泽；明显镜面反射限于稀疏积水。
- 光照：彩色阴影、植被透光、手持光、闪电、植被摇曳；可选 SH9 方向性天光与仅作用于环境光的屏幕空间 AO。主世界预算采用逐角软件阴影比较，预算关闭及其他维度使用阴影过滤选项。
- 下界：独立光照与雾，五类群系具有不同雾色和密度；可选体素彩色光在同一帧执行九个 compute 阶段。
- 末地：Kerr 黑洞天空、独立环境光与按方块身份控制的末地石泛光。
- 后处理：可选 Bloom、色调映射、颜色分级和 FXAA / TAA；自动曝光默认关闭。FXAA 平滑显示空间边缘；TAA 在 HDR 场景中累积静态表面和具备有效运动数据的植被，包含投影抖动、重投影、历史拒绝与其余动态区域隔离。主世界空气高亮与普通水下完整HDR场景共用同一个四分之一尺寸Bloom捕获附件，不再各占一个附件。

## 实现边界

- SSR 是屏幕内物体倒影，屏幕外物体不能凭空恢复；天空倒影有独立来源。浅青到深蓝按水路连续变化，流水侧面使用稳定几何法线，不套水平水面的全反射窗口。
- 多层玻璃、冰和水的完整顺序与厚度尚不具备。竖流水另有晚绘制不透明实体的颜色/距离记录，分数透明实体的完整叠层仍未接入。水体状态已有连续帧、介质、视口和相机/时间跳变保护，但隐藏界面的真实水位及完整水体身份仍有限制。
- 云历史独立于 TAA。云低尺寸重建、倒影稀疏查询、天空底色插值等属于轻量近似，不保证所有边缘都无锯齿、噪点或柔化。
- TAA 累积静态场景和有有效前帧运动数据的植被；实体、透明层、水等动态区域不冒用相机运动。水面旧独立历史未接线，不是开关可启用的现有功能。
- 屏幕空间 AO 处理环境光，方向性天光处理方向响应；「天光环境光」设为0时，方向性天光及其配套方向计算自动停用，标量AO、洞穴最低亮度和夜视保持。开启任一项不表示实现 GI。体积雾、云和透明层的具体合成仍有边界，详见当前工作的技术债条目。
- `VOXY_SUPPORT` 只有适配骨架，打开不等于启用可用的远景渲染。自定义维度沿用根层主世界链。
- 历史画面不代表当前源码；预算减少不等于已经取得指定帧率。主世界整体收尾与缺少的实际性能事实见当前工作。

三个维度使用根目录、`world-1/` 和 `world1/` 薄入口；共享实现在 `program/`、`global/` 和 `lib/`。具体开销或读写问题应回到相关生产者与消费者，不把已停用路径算进当前默认渲染。

普通主世界水下按ITT 3.2的方向处理分色吸收、距离遮蔽、介质色及上下视线响应；开启Bloom时只有较轻的窄范围柔化，近处手部与水底纹理保留细节。关闭Bloom仍有水雾，独立光束只在其开关启用时参与。开启Bloom时水下高精度合成使用主世界独立附件，水面快照保留紧凑格式；从水上看水平水底时折射读取一个颜色/深度配对的场景像素，弱角度倒影以天空环境为主，波面法线不带视差位移。原四方向模糊已退出，已认可的八点光束及颜色／深度配对保持。实际速度与参考观感的最新状态见当前工作。

## 实机视觉排查：优先采用四分屏

**处理模糊、噪点、反射、光束、亮度与颜色等实机反馈时，优先进入临时调色／诊断模式，用同一帧、同一机位的四分屏隔离画面贡献，再根据画面定位源码。** 这是本项目已经采用且用户明确要求延续的工作方式；“调色模式”指临时诊断显示，不表示正式设置页已有固定开关。

用户开启实例并进入相关场景后，已授权代理自行使用 computer use 或当前可用的桌面操作工具，聚焦 Minecraft、输入与排查有关的游戏指令、调整机位、重载光影、截图并读取画面。需要固定场景时，可使用 `/time set noon`、`/weather clear` 等相关指令；同时记录实际维度、机位、时间、天气和影响该效果的设置。具备操作条件时直接推进，不重复要求用户代输指令、代截图或逐次确认重载。

四屏内容应随问题选择，下面是水下贡献排查的已用布局：

| 位置 | 显示内容 | 用途 |
|---|---|---|
| 左上 | 水雾与水下体积光合成前的场景 | 判断噪点是否已经来自几何、水面或前序效果 |
| 右上 | 独立水下体积光／散射层 | 判断光束、颗粒和斜纹是否来自体积光 |
| 左下 | 场景加水雾，排除水下体积光 | 区分雾幕造成的对比下降与体积光噪点 |
| 右下 | 场景加水雾及水下体积光 | 对照上述分量在完整合成中的表现 |

下界可改为原场景、独立反射、局部光照和完整合成；水面可拆出反射命中、反射辐射、法线与最终合成。阴影链路问题应直接显示 `shadowtex0`、`shadowcolor0` 或材质标记，确认生产者实际写入了什么。分屏优先在显示阶段拼接，保持各分量对应同一场景坐标；在画面或记录中标明分屏含义，原始缓冲的显示缩放和色域也要注明，避免把诊断显示自身的变化当成效果缺陷。

操作后必须读取新画面，确认指令、重载和诊断切换确实生效；不能把“已发送按键”当作“游戏已执行”。若自动按键没有触发 Iris 重载、游戏未获得焦点或当前没有可用的桌面控制能力，说明实际受阻的一步，再请用户完成该步。此前自动发送 `R` 未触发重载、用户手动按键有效的情况已发生，后续不得默认自动重载成功。

截图保存到 `qa/runtime-feedback-YYYY-MM-DD/`，记录各屏对应分量及直接观察到的现象；单张截图不能证明动态噪点、拖影或吸积盘流动，需要观察连续画面。临时诊断读完即撤除，并恢复正式画面。源码推断、离线预览与实机观察分别表述，实际截图尚未支持的结论保持未确认。已有水下四分屏及其分量定位见 [实机贡献记录](../docs/archive/实现与取证.md#record-006)，其中的旧图不代表后续版本的效果。10-02 至 10-03 的自主操作、Iris 启停修正及水下反射覆盖边界见 [最新实机记录](../docs/archive/实现与取证.md#record-020)。
