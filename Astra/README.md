## 安装与设置

将 `Astra/` 文件夹放入实例的 `shaderpacks/`，在 Iris 中选择 Astra。设置页提供中文与英文说明。TAA 入口为「后处理 → 抗锯齿 → TAA（可选）」；抗锯齿为本包新增的三选一设置（关闭 / FXAA / TAA），不存在被迁移的旧选项。

| 预设 | 主要取舍 |
|---|---|
| PERFORMANCE（流畅） | 1024 阴影、112 格影距；实体投影关闭，重启时使用 32 格；关闭 SSR、折射、Bloom、平面云、FXAA 及下界体素光 |
| NO_SHADOWS（无实时阴影） | 关闭实时阴影及水下光束；同样关闭 SSR、折射、Bloom、平面云、FXAA 及下界体素光 |
| BALANCED（均衡，默认） | 2048 阴影、256 格影距；开启平面云、SSR、折射、Bloom、FXAA 和下界体素光；空气体积光关闭 |
| ULTRA（极致） | 4096 阴影、256 格影距；更宽阴影核、物理天空和空气体积光 |

三档画质阶梯外另有 NO_SHADOWS 预设。四档显式覆盖画质设置；颜色方案、分层 RGB、曝光、色调映射、自动曝光、饱和度、鲜艳度、对比度与色温独立于画质预设，切换档位保留这些设置。切换档位仍会重置 AO 显示模式和岩石泛光强度。方向性天光与屏幕空间 AO 在四档预设中均关闭，需在「光照」页手动开启。具体值以 `shaders/shaders.properties` 的 `profile.*` 为准，选项范围与出厂值位于 `shaders/lib/settings.glsl`。

「颜色与风格」提供 Astra 原生、暖色自然、冷色通透和柔和四种方案，以及独立夜间蓝移强度。天空调色按白天 / 黎明 / 黄昏 / 夜晚分别设置顶部与地平线；光源调色与维度调色有独立子页。「性能与高级」集中提供阴影、平面云、体积雾、水反射、Bloom 质量，以及云历史、体积雾自适应和实体投影开关；这些控制也在各自效果页出现。

## 实机视觉排查：优先采用四分屏

**处理模糊、噪点、反射、光束、亮度与颜色等实机反馈时，优先进入临时调色／诊断模式，用同一帧、同一机位的四分屏隔离画面贡献，再根据画面定位源码。** 这是本项目已经采用且用户明确要求延续的工作方式；“调色模式”指临时诊断显示，不表示正式设置页已有固定开关。

用户开启实例并进入相关场景后，已授权代理自行使用 computer use 或当前可用的桌面操作工具，聚焦 Minecraft、输入与排查有关的游戏指令、调整机位、重载光影、截图并读取画面。需要固定场景时，可使用 `/time set noon`、`/weather clear` 等相关指令；同时记录实际维度、机位、时间、天气和影响该效果的设置。具备操作条件时直接推进，不重复要求用户代输指令、代截图或逐次确认重载。

四屏内容应随问题选择，下面是水下贡献排查的已用布局：

| 位置 | 显示内容 | 用途 |
|---|---|---|
| 左上 | 水雾与水下体积光合成前的场景 | 判断噪点是否已经来自几何、水面或前序效果 |
| 右上 | 独立水下体积光／散射层 | 判断光束、颗粒和斜纹是否来自体积光 |
| 左下 | 场景加水雾，排除水下体积光 | 区分雾幕造成的对比下降与体积光噪点 |
| 右下 | 场景加水雾及水下体积光 | 对照上述分量在完整合成中的表现 |

下界可改为原场景、独立反射、局部光照和完整合成；水面可拆出反射命中、反射辐射、法线与最终合成。阴影链路问题应直接显示 `shadowtex0`、`shadowcolor0` 或材质标记，确认生产者实际写入了什么。分屏优先在显示阶段拼接，保持各分量对应同一场景坐标；在画面或记录中标明分屏含义，原始缓冲的显示缩放和色域也要注明，避免把诊断显示自身的变化当成效果缺陷。

操作后必须读取新画面，确认指令、重载和诊断切换确实生效；不能把“已发送按键”当作“游戏已执行”。若自动按键没有触发 Iris 重载、游戏未获得焦点或当前没有可用的桌面控制能力，说明实际受阻的一步，再请用户完成该步。此前自动发送 `R` 未触发重载、用户手动按键有效的情况已发生，后续不得默认自动重载成功。

截图保存到 `qa/runtime-feedback-YYYY-MM-DD/`，记录各屏对应分量及直接观察到的现象；单张截图不能证明动态噪点、拖影或吸积盘流动，需要观察连续画面。临时诊断读完即撤除，并恢复正式画面。源码推断、离线预览与实机观察分别表述，实际截图尚未支持的结论保持未确认。已有水下四分屏及其分量定位见 [实机贡献记录](../docs/2026-10-01-complementary-netherrack-reflection.md)，其中的旧图不代表后续版本的效果。10-02 至 10-03 的自主操作、Iris 启停修正及水下反射覆盖边界见 [最新实机记录](../docs/2026-10-03-live-performance-inspection.md)。

## 当前功能

- 水：动态法线、屏幕空间反射与折射、按水中距离计算的吸收、解析焦散及水下光束。
- 大气：渐变与物理天空、可配置分辨率的平面云与日月遮挡、全天候天空与云反射、独立世界空间云影缓存、雾、空气透视、生物群系染色，以及可选的步进体积雾（雾页开关，默认关闭）。平面云的独立时域历史可通过「云历史平滑」开关控制，以透射权重一阶矩为代表位置、真实前帧参数重投影，独立于 TAA。
- 雨湿地面：木材、土壤与石材采用不同暗化和轻微光泽；明显镜面反射限于稀疏积水。
- 光照：彩色阴影、植被透光、手持光、闪电、植被摇曳；可选 SH9 方向性天光与仅作用于环境光的屏幕空间 AO；软件与硬件阴影比较模式可选。
- 下界：独立光照与雾，五类群系具有不同雾色和密度；可选体素彩色光在同一帧执行九个 compute 阶段。
- 末地：Kerr 黑洞天空、独立环境光与按方块身份控制的末地石泛光。
- 后处理：可选 Bloom、色调映射、颜色分级和 FXAA / TAA；自动曝光默认关闭。FXAA 平滑显示空间边缘；TAA 在 HDR 场景中累积静态表面和具备有效运动数据的植被，包含投影抖动、重投影、历史拒绝与其余动态区域隔离。

## 实现状态与边界

- 地形光照在 gbuffers 阶段计算；后续效果仍使用深度、材质及场景颜色缓冲，并非没有中间缓冲。
- FXAA 开启时增加完整画面的显示颜色阶段；1080p 下其双纹理约 31.64 MiB，关闭时停用该阶段。云影缓存的双纹理约 256 KiB，云图范围之外继续查询原密度场。
- TAA 使用独立 HDR 历史、动态遮罩、4×1 帧状态及全分辨率植被运动数据，1080p 双纹理合计约 67.24 MiB，其中运动数据约 31.64 MiB；关闭时停用相关阶段并缩小资源。帧状态保留实际植被时间相位。其解析在显示变换前，Bloom、空气光束与最终水下粒子仍按当前帧合成。
- TAA 植被用真实前帧时间、雨量和强度重建同一顶点的历史形变，再传递运动及预期深度。实体、手持物、透明层、水、天气、云及积水仍不累积历史；水下也采用当前帧。双线性重建可能柔化细节；没有本轮游戏画面或帧时数据。
- 方向性天光从当前天空及云计算 SH9，主世界空气侧按法线求方向响应，保留洞穴最低亮度与夜视。关云时也能工作，不依赖 TAA；不是 GI。与屏幕空间 AO 同时开启时，AO 合成阶段以 bent normal 重新求值该方向响应：只替换环境天光的方向分量（材质响应单独保留在 colortex27），洞穴最低亮度、方块光、直射与自发光不受影响；未开 AO 或方向无效 / 无可见样本时回退几何法线。
- 屏幕空间 AO 采用半分辨率采样和深度 / 法线保边合成，仅处理主世界空气侧普通不透明地形。开启后顶点 AO 也仅遮蔽环境光，与 SSAO 取较暗一项，直射、局部光和发光保持独立。当前要求开启实时阴影，以取得独立顶点 AO；不依赖 TAA。全尺寸环境光使用 R11F_G11F_B10F，法线使用 RGBA8，顶点 AO 以 7 位存于法线附件 A 通道；关闭后缩小资源并停用阶段。同时开启方向性天光时，AO 核额外产出可见半球的 bent normal（半分辨率 colortex26，可见度加权方向均值，几何法线回退），经同一套深度 / 法线保边权重重建后消费；全尺寸方向天光响应 colortex27 使用 R11F_G11F_B10F。方向性天光或 AO 单独关闭时，26/27 缩为 1×1 且不参与。紧凑 HDR 与七位 AO 降低了存储精度，详见本轮实施记录。
