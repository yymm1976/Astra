# Iris 1.11.2 + MC 26.2 引擎能力实测（2026-10-17）

用途：为 `shader_research/2026-10-17-可参考机制调研-Astra缺口.md` 提供引擎侧证据。
来源：本机实例 `D:/zhenhebao/.minecraft/versions/生电优化整合包 (Fabric)/mods/iris-fabric-1.11.2+mc26.2.jar` 解包（844 个 .class，位于 `_analysis/irispk/`），用 JDK17 `javap -p -c` 反编译与常量池字符串提取。**这是反编译结果，不是官方文档**，行为以实际启动为准。

## 1. 可选特性（FeatureFlags）

`javap -p net.irisshaders.iris.features.FeatureFlags` 实测，共 14 项：

`SEPARATE_HARDWARE_SAMPLERS、HIGHER_SHADOWCOLOR、CUSTOM_IMAGES、PER_BUFFER_BLENDING、COMPUTE_SHADERS、TESSELLATION_SHADERS、ENTITY_TRANSLUCENT、REVERSED_CULLING、BLOCK_EMISSION_ATTRIBUTE、CAN_DISABLE_WEATHER、SSBO、FADE_VARIABLE、TEXTURE_FILTERING、UNKNOWN`

- 每项由两个 BooleanSupplier 把关（Iris 侧要求 + 硬件侧要求）；硬件侧调用 `IrisRenderSystem` 的 supportsCompute / supportsSSBO / supportsImageLoadStore / supportsBufferBlending / supportsTesselation。
- Astra 当前只声明 `iris.features.optional=CUSTOM_IMAGES COMPUTE_SHADERS`（`Astra/shaders/shaders.properties:883`）；全树 `IRIS_FEATURE` 宏 0 命中（实测 grep）。

## 3. 程序阶段（ProgramGroup）

`javap -p net.irisshaders.iris.shaderpack.loading.ProgramGroup` 实测 10 组：`Setup、Begin、Shadow、ShadowComposite、Prepare、Gbuffers、Deferred、Composite、Final、Dh`。

- 对应存在 `net/irisshaders/iris/shadows/ShadowCompositeRenderer.class` 与 `ShadowRenderer.class`，即 **shadowcomp 系列可用**；Astra 全树 shadowcomp 0 命中（实测）。
- `Dh` 组对应 Distant Horizons 集成；Astra 只有 Voxy 占位 stub，无 DH 程序。

## 4. 纹理与存储（实证来自可读第三方包）

- 自定义 3D 纹理可用：`_analysis/batch5_unpack/escheridia/shaders/shaders.properties:80` = `customTexture.blueNoiseTex = /textures/stbn.bin TEXTURE_3D RGB8 128 128 64 RGB UNSIGNED_BYTE`，且该包把 CUSTOM_IMAGES 列为 required（`:14`）。
- R32UI 体素 image 可用：同文件 `:19-66`。
- SSBO 可用：escheridia 声明 SSBO required；Arc 的 lib/ssbo/ 与 program/setup.csh 用 compute + SSBO 预生成采样圆盘。
- Astra 现状：customTexture 12 处（全 2D PNG）、image 4 处（下界体素 3D 链）、主世界无 SSBO。
